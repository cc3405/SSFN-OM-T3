# 07 · 测试、风险与迭代计划

## 测试原则
每项机构先独立测试，再组合测试，最后进行完整表演。每次只改变一个变量；记录配置、结果、失败原因和下一步。所有载人测试先配重后低速进行，并由成人监督。

## 验收矩阵

| 编号 | 测试 | 方法 | 通过标准 |
|---|---|---|---|
| T01 | 门口包络 | 用实际净宽搭建门框，车辆和购物车按规定状态通过 | 无碰撞、无拆除关键结构的临时操作 |
| T02 | 静态承载 | 逐步增加等效乘员载荷 | 车架无明显变形、连接无松动 |
| T03 | 乘员姿势 | 全行程操作曲柄、转向和制动 | 手脚不触地、不碰夹点 |
| T04 | 车辆直行 | 空载与牵引购物车各运行多次 | 方向可控，无持续偏航 |
| T05 | 转弯 | 在模拟通道完成最小转弯 | 购物车不顶撞车辆、不翻覆 |
| T06 | 制动 | 载人/配重并牵引购物车停车 | 可控停车，停车后保持稳定 |
| T07 | 快拆连接 | 反复连接、锁止、释放 | 不误脱、不需复杂工具 |
| T08 | 购物车自主回收 | 轻载、满载、不同释放位置测试 | 自主进入目标区并停住 |
| T09 | 独立卸载 | 三件物品连续卸载 | 三件均落入结账区，无掉落 |
| T10 | 表演节奏 | 全流程计时 | 8 分钟内完成，目标 7:15 |
| T11 | 连续可靠性 | 连续完整模拟 5 次 | 至少 4 次无关键失误 |
| T12 | 赛场复位 | 从初始布置完整复位 | 能在允许准备时间内准确复位 |

“多次”在团队内部统一为每个独立机构至少 20 次成功重复后再定型；这是工程验收目标，不是题目评分条款。

## 风险登记表

| 风险 | 严重度 | 预防措施 | 应急方案 |
|---|---|---|---|
| 车辆倾覆/乘员滑落 | 极高 | 低重心、宽轮距、限速、配重测试 | 立即停止载人测试，重做底盘 |
| 乘员脚触地 | 高 | 封闭脚部空间、固定脚托 | 调整座椅/脚托，未解决前不排练 |
| 传动夹手 | 高 | 护罩、限位、断电/停机检修（若有电气件） | 停止运行，移除危险部件 |
| 购物车脱钩 | 高 | 双重防脱、可视锁止检查 | 停止运行，重新设计连接 |
| 自主回收偏航或过冲 | 高 | 限速、机械止挡、重复校准 | 降低储能、调整轮组；不得人工补推 |
| 卸载物品掉落 | 中高 | 托盘挡边、软质限位 | 独立操作单件，复位后继续 |
| 机构卡滞 | 中 | 低摩擦铰链、宽容差、备件 | 使用手动复位，不强拉 |
| 超预算 | 中 | 采购审批、收据台账、预留余量 | 冻结装饰和非关键采购 |
| 演出超时 | 中 | 分段计时、固定台词 | 缩短表演停顿，不跳过任务步骤 |

## 每次排练检查表
- [ ] 车架、车轮、轴、螺栓无松动。
- [ ] 转向与制动工作正常。
- [ ] 链条/皮带张力正常，护罩固定。
- [ ] 购物车连接销和二次保险齐全。
- [ ] 购物车回收机构已正确复位并锁止。
- [ ] 卸载台底座稳定，铰链与止挡正常。
- [ ] 三件物品及替代品齐全、可见、耐搬运。
- [ ] 清单、服装、音乐与风格道具齐全。
- [ ] 场地边界和人员安全通道已标记。
- [ ] 计时器、记录表和工具箱已准备。

## 迭代节奏
- 第 1 周：规则澄清、纸面设计、场地尺寸确认。
- 第 2 周：车辆与购物车低成本原型。
- 第 3 周：推进、转向、制动、连接器单项测试。
- 第 4 周：卸载台原型与三件物品适配。
- 第 5 周：购物车回收机构测试；依据官方答复决定是否继续储能方案。
- 第 6 周：集成测试、动作编排、风格元素初稿。
- 第 7 周：全流程彩排、故障注入、调整结构。
- 第 8 周：冻结设计、制作备件、提交材料复核、模拟比赛。

实际周期可按队伍日程伸缩；安全和规则核验不可跳过。
