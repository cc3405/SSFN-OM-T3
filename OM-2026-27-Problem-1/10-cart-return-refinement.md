# 10 · 购物车回收简化修订

## 采用的方向
车辆先把购物车精确带到购物车区域边缘附近的固定释放点，停车后直接断开牵引。把复杂的长距离自主驱动改为释放后的短行程自主入位。

## 必须保留的规则动作
题目要求购物车在车辆停止并释放后，自主驶入购物车区域并停住。因此：
- 车辆送到释放点属于运输和定位。
- 断开后购物车仍须发生可观察的自主位移，越过区域边界并停住。
- 若购物车已完全在区域内，释放后静止不动，不能稳妥证明完成“自主驶入”，不作为本方案的合规路径。

## 机械概念
1. 在地面实测区域边界，设置固定释放标记。
2. 车辆以低速把购物车带到释放标记外侧，先完全停车。
3. 使用简单机械快拆完全断开牵引。
4. 购物车自身携带的低能量短行程机构解锁，使其自行越过边界。
5. 采用低速限位/制动使购物车停住，不依靠撞击边界停车。

## 规则风险与澄清
制作前必须向官方确认：购物车是否必须在脱离车辆后发生可观察位移；短距离移动是否足够；弹簧/橡皮筋/发条等自带储能是否允许；快拆能否联动解锁；车辆将购物车送到区域边缘后再由购物车自行越界是否符合题意。未得到答复前，不定型储能机构、不宣称合规。

## 验收标准
- [ ] 车辆将购物车送至区域外的固定释放点。
- [ ] 车辆完全停止后再断开。
- [ ] 购物车完全脱离车辆后靠自身机构发生可观察位移。
- [ ] 无队员、车辆或外部物体补推/牵引。
- [ ] 购物车越过区域边界并停住，至少一个接地点在区域内。
- [ ] 官方确认后，空载与满载各连续20次成功。

**结论：** 采用“精确送位 + 极短自主行程”作为下一轮原型方向；自主行进的具体机构仍须官方澄清后定型。
