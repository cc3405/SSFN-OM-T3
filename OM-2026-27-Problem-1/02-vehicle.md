# 02 · 乘坐式车辆系统

## 设计目标
车辆必须原创、可乘坐、自成一体，乘员在行进时不接触地面；能牵引购物车、通过标准门口并在购物车释放点可靠制动。优先选择低重心、低速、易维修的四轮平台。

## 推荐结构

### 底盘与座舱
- 矩形主框架采用木材或轻型金属型材；材料选择以队员加工能力、连接可靠性和总成本为准。
- 座椅固定在底盘主梁上，乘员重心尽量低；座椅有侧向支撑，避免急转时滑落。
- 脚部空间完全位于车体轮廓内，脚踏/脚托固定，确保车辆移动时脚不会触地。
- 车体外缘加软质防撞条；所有突出件不得增加门口通行风险。
- 结构连接处使用螺栓、垫片和防松螺母；关键承载点不只靠热熔胶或胶带。

### 推进
建议采用手摇曲柄—链条—后轴传动：
1. 乘员转动带护罩的曲柄。
2. 链条带动后轴链轮。
3. 后轴驱动两个后轮；必要时采用差速结构，或以单侧驱动并通过试验确认转弯不拖拽。
4. 曲柄具有可拆卸手柄或折叠把手，便于运输和防止误触。

传动比不要先按理论速度定型。先制作可换链轮/皮带轮的试验台，以低速、可控启动、容易停车为目标。曲柄不得扫到乘员膝部或购物车连接件。

### 转向与制动
- 前轮转向用刚性横拉杆同步，减少左右轮转角差异。
- 机械限位防止转向拉杆过转或轮胎碰车架。
- 制动应能在载人和牵引购物车时停车；优先使用可调摩擦制动，避免仅靠传动阻力减速。
- 制动拉索、连杆与车轮保持间隙，外露活动部位加护罩。
- 在正式表演前，必须在实际载荷和地面条件下测量停车距离。

### 购物车连接
- 牵引点尽量低，位于车辆纵向中心线附近。
- 使用球头/铰接结构或带垂直自由度的双耳连接，允许地面微小不平而不抬起购物车。
- 插销采用防脱设计，并增加可视化“已锁定”标记。
- 连接器在行进中不允许触地或勾住车轮。
- 快拆动作在停车并制动后执行，避免边移动边解锁。

## 初步尺寸流程（必须实测）
1. 先测比赛场地门洞净宽、车体最大宽度及把手突出量。
2. 预留门框两侧安全间隙；不把“刚好能过”当作合格。
3. 用胶带在地面标出最小转弯通道，连购物车一起通过。
4. 以乘员实际坐姿检查膝部、手摇曲柄、转向手柄和车架干涉。
5. 完成载人静载、低速动态、紧急制动和侧向稳定测试。

## 安全与维护
- 传动链条、链轮、曲柄轴端全部加防夹护罩。
- 不允许乘员站立蹬地、拖脚或借地面助推。
- 关键螺栓每次排练前点检；链条张力和车轮紧固每次运行后复检。
- 车辆只能在成人监督下进行载人测试；先用配重测试，再进行低速载人测试。
- 备件：链条快扣、连接销、螺母、垫片、制动线、扎带、工具。

## 车辆验收表
- [ ] 原创车辆结构和推进系统由队伍设计制作。
- [ ] 乘员可安全坐稳并独立操控。
- [ ] 车辆行进时乘员不接触地面。
- [ ] 不依赖外部电源、斜坡或外部风力。
- [ ] 连接购物车后能直行、转弯、制动。
- [ ] 通过标准门口并留有安全余量。
- [ ] 释放购物车时车辆可稳定停止，且停在起始线上或其外侧。
- [ ] 所有夹点、锐边、突出件均已处理。
