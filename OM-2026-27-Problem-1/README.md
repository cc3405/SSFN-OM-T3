# OM 2026–2027 · 长期题 1「OMER 的购物服务」

> **当前整合基线：** [17 · 整合版完整竞赛方案](17-integrated-complete-plan.md)。本目录规则依据仅为仓库中的 `D5/1111111-main/1.md`；当季《活动手册》和官方澄清仍须另行核验。
>
> **预算口径：** 题目文件 B4 的正式上限为 US$165；团队计划支出为 **US$160**，另有 **US$5 价格波动预留**，总额最高 US$165。从零开始且没有任何零件，不能假设能在该预算内买齐安全载人车辆、购物车和卸载装置。
>
> **状态：** 当前为纸面方案，尚无实体零件、原型、测试或规则预批准。青少年不得独自进行载人测试；载人结构、制动、转向和轮轴须由合格成人/专业人员审查。
