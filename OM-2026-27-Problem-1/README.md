# OM 2026–2027 · 长期题 1「OMER 的购物服务」

> 本目录是基于 `D5/1111111-main/1.md` 建立的独立竞赛方案。该题目文件是本方案唯一规则依据；其他仓库文件不作为设计输入。正式制作前，必须再核对当季 OM 活动手册与官方澄清。

## 方案目标

设计一套在 8 分钟内可重复完成的完整表演系统：队员乘坐并操作原创车辆，连接并牵引购物车完成购物；购物助理处理订单和缺货替代；原创、独立于车辆的卸载装置将三件物品从购物车转移至结账区；车辆牵引购物车穿越起始线后释放，购物车自主驶入购物车区域并停住。

**工程优先级：合规与稳定 > 任务完成率 > 可重复性 > 创造性加分。** 不以高风险复杂机构换取纸面创意。

## 设计概念：OMER「移动微型超市」

叙事包装为一支未来社区配送小队：车辆是“移动服务站”，购物助理是“订单协调员”，购物车是可分离的“补给舱”，卸货装置是“结账分拣台”。所有戏剧元素必须服务于真实任务，不遮挡物品、不干扰安全、不延误关键动作。

## 不可妥协的规则边界（来自指定题目文件）

1. 表演时限 8 分钟；总成本不得超过 165 美元。
2. 车辆必须原创、可乘坐、自成一体；至少一名队员乘坐并操作，车辆行进时乘员不得接触地面。
3. 车辆必须连接购物车并带着购物车行进；整套车辆需通过标准门口。
4. 不得依赖外部动力源（例如交流电源线、斜坡、外部风扇）。
5. 三件清单物品中恰有一件缺货；购物助理必须批准替代品；三件物品须在释放购物车前交给操作员。
6. 卸载装置须由队伍原创制作、独立于车辆，并将购物车中的物品拿起放入结账区；队员可直接人力操作。
7. 车辆牵引购物车穿过起始线所在垂直平面后，车辆停止并释放购物车；购物车须自主驶入购物车区域并停住，至少一个接地点位于区域内；车辆保持在起始线上或起始线之外。
8. 购物助理由队员扮演，须完成订单交付、替代品批准与结账核对。
9. 五项风格项目包含：清单中一件物品的艺术质量、音乐的创造性使用、两项队伍自选项目、前四项的整体效果。

## 设计假设与待官方核实

此方案将车辆暂定为**队员手摇驱动、四轮低重心底盘**，购物车回收暂定为**购物车自身储能驱动、限速后自主行驶**。这两项是工程概念，不是题目文件对具体技术的认可。购物车自主驱动尚未通过规则确认，**不得在官方答复前定型或宣称合规**。制作前应针对“自主行驶”的定义、储能装置是否允许、购物车是否可改装、标准门口净宽、购物车区域尺寸、物品规格、结账区边界和卸载装置边界提交澄清或向裁判确认。

## 决策门

- Gate 0：逐条读当季手册和澄清；未通过不切料。
- Gate 1：纸板/木条全尺寸模型验证门宽、转弯、车身包络和人员姿势。
- Gate 2：车辆带载牵引购物车完成 20 次往返，无倾覆、脱钩或人员触地。
- Gate 3：卸载装置连续 20 次完成三件物品转移。
- Gate 4：购物车自主回收在规则确认后连续 20 次进入区域并停住。
- Gate 5：全流程 8 分钟内连续完成 5 次；至少 4 次零关键失误，方可定型。

**重要：** 所有尺寸、载荷、速度和机构参数均须通过实际场地和实物测试确定；本方案不把未测数据伪装成规则事实或性能承诺。当前方案成熟度为“设计方案/原型前阶段”，不是已建成的竞赛成品。
