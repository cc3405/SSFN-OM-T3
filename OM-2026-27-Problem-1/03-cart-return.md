# 03 · 购物车与自主回收系统

## 任务定义
购物车随车辆完成购物；车辆牵引购物车穿过起始线所在垂直平面；车辆停止后释放购物车；购物车不再由车辆牵引，自主驶入购物车区域并停住，至少一个接地点落在区域内。车辆保持在起始线上或起始线之外。

## 购物车本体
- 使用低重心、宽轮距底架；物品放置区有围边但不遮挡物品。
- 轮轴平行，轮子滚动阻力尽量一致；轮胎/轮面需适配比赛地面。
- 购物车前端连接点与储能驱动组件分离，避免快拆影响驱动。
- 车体标注前进方向、释放点和调节刻度，便于每次复位。

## 自主回收概念：预储能驱动 + 限速机构
工程候选方案为购物车自身的弹簧储能驱动：
1. 赛前由队员将购物车驱动弹簧预储能并锁止。
2. 购物车被车辆牵引期间，驱动机构保持机械锁止，不干扰牵引。
3. 车辆停止、完成规定释放动作后，解锁机构释放储能。
4. 齿轮减速与摩擦/离心限速机构控制速度，避免冲出区域。
5. 机械终点缓冲与可调制动片帮助购物车停住。

这只是候选设计。**在官方确认允许前，不应投入不可逆制作。** 若储能驱动被裁判认定不符合题意，立即停用此设计；不能改用人推、拉线、磁吸牵引、外部风扇或现场斜坡来冒充自主行进。

## 调试方法
- 用比赛同材质地面搭建测试区，标出释放线与目标区边界。
- 先测空车，再测三件物品满载；分别记录启动成功率、行进距离、偏航量和停止位置。
- 每次只调整一个变量：储能量、齿轮比、限速器摩擦、车轮定位或配重位置。
- 使用可调机械限位控制最大行程；避免单纯靠不断提高弹簧能量来解决距离不足。
- 用纸质记录表保存每次测试参数，禁止凭记忆调节。

## 方向稳定
- 左右轮直径、轮面和轴承阻力尽量一致。
- 车轮轴线与车体中心线垂直；在地面直线测试中观察偏航。
- 驱动轮左右输出尽量对称；若结构无法差速，降低驱动扭矩并测试转弯后回收。
- 通过可移动配重微调重心，但所有配重必须固定。

## 停止与区域适配
- 以“最坏情况”调试：最大储能、最轻载荷、最低滚阻、略有偏航。
- 目标不是冲到区域深处，而是稳定进入边界并安全停住。
- 设计软质前端缓冲，不得靠撞击边界来保证停住。
- 每次正式运行前检查储能锁止、解锁拉杆、限速器、车轮和目标区对准。

## 备选路线
若官方不认可弹簧储能自主驱动，先向裁判确认允许的“购物车自主行进”实现方式，再选择完全由购物车自身携带且符合规则的机构。不得未经确认改用重力坡道、队员牵引线或外部动力。

## 验收
- [ ] 释放动作发生在车辆停止之后。
- [ ] 购物车与车辆完全脱离后自行运动。
- [ ] 没有人、车辆或外部物体提供推力/牵引。
- [ ] 购物车进入购物车区域，至少一个接地点在区域内。
- [ ] 购物车最终停住且未碰撞伤人或损坏场地。
- [ ] 轻载、满载、不同地面摩擦条件下均完成重复测试。
