# 05 · 8 分钟表演编排

## 叙事结构
标题建议：**《OMER 超市：最后一单》**

角色：
- 驾驶员/车辆操作员：负责驾驶、牵引、接收物品。
- 购物助理：负责订单、缺货说明、替代批准和结账核对。
- 卸载员：操作独立卸载台。
- 其他队员：可兼任顾客、仓储协调员、音乐/音效表演者；角色数量按队伍人数调整。

所有队员角色、台词、服装、音乐和道具由队伍原创。不得让表演干扰车辆安全或规则动作。

## 时间轴（目标总时长 7:15，留 45 秒余量）

| 时间 | 场景/动作 | 裁判必须看见的证据 |
|---|---|---|
| 0:00–0:35 | 开场：微型超市启动 | 车辆、购物车、卸载台和角色清楚呈现 |
| 0:35–1:10 | 购物助理交付订单 | 清单明确显示三件物品 |
| 1:10–1:35 | 驾驶员连接购物车并确认锁定 | 连接动作可见，车辆可控 |
| 1:35–3:20 | 车辆带购物车进入购物区购物 | 车辆乘员不触地，购物车持续连接 |
| 3:20–4:00 | 宣布一件缺货并提出替代品 | 缺货物品与替代品明确区分 |
| 4:00–4:20 | 购物助理批准替代 | 明确口头批准+可见批准标记 |
| 4:20–4:50 | 三件物品交给操作员并完成订单检查 | 三件物品均可见且与订单对应 |
| 4:50–5:15 | 车辆牵引购物车到结账区并停车 | 购物车仍连接；车辆完全停止 |
| 5:15–6:15 | 独立卸载台转移三件物品 | 三件物品逐件落入结账区 |
| 6:15–6:35 | 购物助理结账核对 | 订单与三件物品逐项核对 |
| 6:35–6:55 | 车辆牵引购物车穿过起始线垂直平面 | 车辆与购物车完整通过规定平面 |
| 6:55–7:10 | 车辆停车、释放购物车、自主回收 | 购物车自主进入区域并停住 |
| 7:10–7:15 | 结尾定格 | 车辆位置、购物车位置、物品位置清楚 |

时间分配是排练目标，不改变题目规定的 8 分钟上限。若场地路线较长，应压缩喜剧停顿，不得压缩关键规则动作。

## 关键台词模板（需原创改写）
- 交单：“本单三件：A、B、C，请逐项完成。”
- 缺货：“B 暂时缺货，我们申请以 B′ 替代。”
- 批准：“我已核对，批准 B′ 作为 B 的替代品。”
- 结账：“A、B′、C，三件齐全，订单完成。”

必须确保批准发生在替代品被作为完成订单的物品使用之前；若官方澄清对顺序另有要求，以官方要求为准。

## 舞台调度
- 所有角色初始位置遵循题目文件的准备区、起始线和购物车区域要求。
- 购物助理交单时站在裁判可见位置，不挡车辆通道。
- 购物区取物时，物品直接放入购物车并保持可见。
- 卸载台放在结账区边缘但不越界；具体位置按场地边界和裁判说明确定。
- 购物车回收路径不得穿过队员站位；人员离开车辆与购物车运行通道。

## 风格项目建议
1. 艺术物品：将清单中的一件物品设计为可见、耐搬运、原创制作的艺术作品。作品应本身有艺术质量，而不是只贴装饰。
2. 音乐：制作一个短小原创“订单动机”，在交单、替代批准、卸载和回收时以不同节奏/音色变化，音乐与动作形成呼应。
3. 自选风格 A：服装与角色造型——用统一色彩编码角色职能。
4. 自选风格 B：道具/舞台视觉——把结账台、购物车标识和车辆外观统一为一个世界观。
5. 整体效果：每个元素均服务“微型超市”主题，避免无关段子与过长对白。

## 视觉证据原则
裁判应在几秒内看清：订单三件物品、缺货项、替代品、批准动作、三件物品转交、三件卸载、购物车释放、购物车最终位置。所有关键标识使用大字和高对比色；不依赖观众听懂复杂对白。
