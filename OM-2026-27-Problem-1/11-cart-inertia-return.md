# 11 · 购物车惯性滑行回收方案（优先原型）

## 核心构想
优先利用购物车在被车辆牵引行进时已经获得的动量，而不是增加弹簧、发条或电机。车辆到达起始线允许的停车位置后制动停止；购物车凭自身惯性继续向前滚动一小段，越过购物车区域边界并停住。

这是低零件数、低能量、易调试的候选方案。**是否符合“购物车自主行进”必须先向官方澄清；本文件不把惯性滑行视为已获批准。**

## 关键机械结构：可前滑的失动式牵引连接
普通刚性牵引杆会在车辆刹停时把购物车一并拉停，不能直接实现本方案。原型应研究：
- 车辆端安装带纵向导向槽的牵引座；
- 购物车端使用圆头滑销/滚轮销，在导向槽内有受控的前后相对行程；
- 车辆制动停止后，购物车凭惯性沿导向槽向前相对滑行；
- 到达导向槽行程末端时，机械脱扣使购物车与车辆完全分离；
- 车辆保持静止并停在题目允许的位置，购物车继续滚动并进入目标区域。

连接结构应采用封闭导向、防夹护罩、机械限位和可视锁定标记。不得使用弹射、弹簧助推或外部牵引来增加滑行距离。失动槽行程和脱扣方式须以实测及官方答复为准。

## 动作时序
1. 车辆以稳定、低速牵引购物车完成任务，并完整通过起始线所在垂直平面。
2. 车辆在起始线或其外侧的标记位置制动至完全停止。
3. 购物车因惯性在失动连接槽内相对车辆前滑。
4. 连接销到达行程末端，购物车与车辆脱离。
5. 购物车继续依靠自身剩余动量滚入购物车区域，并因轮胎滚阻/轴承阻力自然减速停住。
6. 车辆不得跟随购物车越过规定位置；队员不得补推或拉动购物车。

## 设计边界
- 释放动作必须发生在车辆停止之后；验证“车辆停止”与“购物车仍在相对前滑”能否同时成立。
- 若规则要求车辆停止后由队员主动操作快拆，自动惯性脱扣可能不符合要求，必须先澄清。
- 不用坡道、外部风扇、电源、磁吸、拉线、人推或弹簧弹射。
- 不能以车辆尚未停止时提前脱钩来规避时序要求。
- 必须记录完全脱离的明确时刻，不能把仍连接的滑行误称为已释放。

## 低成本原型
1. 用木条/铝型材制作可调长度直线失动槽，先用配重小车代替正式购物车。
2. 在平整、与比赛地面相近的地面上，以低速拖行后制动车辆端，观察购物车相对滑行距离。
3. 逐级调整释放前速度、车轮滚阻、载荷和失动槽行程；每次只改一个变量。
4. 测量车辆完全停止时刻、购物车脱离时刻、脱离后的滑行距离、偏航和最终停止位置。
5. 先做软质围挡和安全捕捉区，避免小车冲出测试区；稳定后再制作正式原型。

## 初筛测试矩阵
空车/满载、低速/目标速度、不同滚阻地面、直线/轻微角度偏差、不同失动槽行程。每种工况至少重复10次初筛；官方确认后，轻载和满载各至少20次连续成功才考虑定型。记录数据，不凭感觉判断。

## 官方澄清问题
1. 车辆完全停止后，购物车凭此前牵引获得的惯性继续滚动，是否属于购物车“自主行进”？
2. 车辆停止后，购物车在失动式连接槽内继续前滑、随后自动脱扣，是否满足“车辆停止后释放购物车”？
3. 规则是否要求车辆停止后由队员主动执行释放，还是允许由购物车惯性触发机械脱扣？
4. 购物车完全脱离车辆后继续依靠剩余惯性滚入区域，是否满足自主驶入要求？

在官方答复前，本方案只作为优先原型研究方向，不宣称合规。

## 验收条件
- [ ] 车辆先完全停止，录像可清楚辨认停止时刻。
- [ ] 购物车在车辆停止后才完全脱离。
- [ ] 脱离后购物车依靠剩余惯性发生可观察位移，无外力补推/牵引。
- [ ] 购物车进入区域，至少一个接地点在区域内并最终停住。
- [ ] 车辆保持在起始线上或起始线之外。
- [ ] 无夹手、脱轨、倾覆、撞击边界或失控风险。
- [ ] 官方书面确认该动作顺序和惯性方式可接受。
