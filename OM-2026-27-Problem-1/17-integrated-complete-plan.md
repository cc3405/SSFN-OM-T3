## 1. 项目目标与完成定义

在 8 分钟内呈现原创购物服务表演，并完成全部关键动作：

1. 原创、自成一体、可乘坐的车辆由至少一名队员乘坐并操作；车辆行进时乘员不接触地面。
2. 车辆连接并牵引购物车通过购物流程；整套车辆可通过标准门口。
3. 购物助理把三件物品的订单交给操作员；购物区内一件指定物品缺货，队伍取用一件替代品，购物助理明确批准。
4. 三件物品在释放购物车前交给车辆操作员。
5. 在结账区使用原创、独立于车辆的卸载装置，将购物车内三件物品拿起并放入结账区。
6. 结账后车辆继续前进，直到连接的购物车穿过起始线垂直平面；车辆停止并释放购物车；购物车随后进入购物车区域并停住，至少一个接地点在区域内；车辆停在起始线上或起始线之外。
7. 在 8 分钟内完成风格表演、解题和题目要求的承重测试/相关检查；提前结束时发出清楚的完成信号。

**优先级：** 规则合规与人员安全 > 全部任务动作可见 > 稳定重复 > 工程创造性 > 表演装饰。

## 3. 整体设计架构

采用“OMER 移动微型超市”主题。工程上分成四个独立对象：

- **A. 乘坐式服务车：** 队伍原创低重心四轮人力车。概念推进为乘员坐姿手摇曲柄，经链条/皮带和减速传动驱动车轴；机械转向、独立机械制动。该方案仅是待教练/工程审查的概念，不是已验证载人设计。
- **B. 购物车与牵引/释放器：** 低重心购物车，连接点靠近车辆中心线、位置低；使用可目视确认的插销和二次防脱。返回候选为**低能量失动槽/惯性释放**：车辆带购物车越过起始线后制动，购物车在短行程槽内相对车辆继续滚动，到达槽端触发完全脱离，依靠自身剩余动量驶入购物车区域。禁止把弹簧弹射或高能量储能机构作为默认方案。
- **C. 独立卸载台：** 自立式三工位手动翻转托盘架；底座宽、低重心，托盘有软挡边，手柄远离夹点。与车辆没有任何机械连接。
- **D. 购物服务表演：** 购物助理、订单卡、缺货/替代展示、原创音乐动机和主题服装。表演不得遮挡裁判观察关键动作。

### 3.1 车辆结构概念

目标是四轮、低重心、低速、可控，而不是追求速度。概念模块：

1. **承载底盘：** 由队伍设计并制作，形成清楚的乘员载荷路径；关键承载连接不能只依赖胶水、胶带或热熔胶。
2. **座舱：** 固定座椅、侧向防滑支撑、封闭脚托/脚部区域；乘员手脚在车辆行进时不触地。
3. **推进：** 乘员坐姿手摇曲柄，通过链条或同步带驱动后轴；所有链轮、曲柄和夹点设护罩。传动比先做台架试验，不在纸面指定未经计算的速度。
4. **转向：** 前轮连杆同步，设置机械限位；转向全行程不得与车架、轮胎、脚托或牵引器干涉。
5. **制动：** 独立机械制动，必须在乘员等效载荷并牵引购物车时可控停车；不得用脚拖地、木块摩擦或仅靠传动阻力替代。
6. **牵引点：** 低位、接近车辆纵向中心线；允许地面微小起伏，不可顶起购物车；插销加二次保险，并有“锁定/未锁定”可视标识。
7. **门洞包络：** 以实际标准门洞净宽、把手突出量和转弯路径为输入；设计留有安全余量，不做“刚好擦边”方案。

**安全边界：** 由于操作者是青少年，载人底盘、车架、轮轴、转向和制动必须由有资质/经验的成人或专业人员审查。先做结构计算/材料核验和静态配重，再做封闭区域低速测试。任何结构、制动或转向疑点都意味着停止载人测试。

### 3.2 购物车与返回机构

购物车应满足：低重心、宽轮距、轮轴平行、无锐边、物品不会掉落；三件物品从侧面和上方均可看见。购物车自身不带电机，不连接外部电源。

**首选研究方向：失动槽 + 惯性短行程：**

- 牵引杆在封闭导槽中有受控短行程，销轴有防脱结构和软质端挡。
- 正常购物时牵引销位于工作端，车辆稳定牵引购物车。
- 购物车越过起始线垂直平面后，车辆按动作脚本平顺制动；购物车因惯性在导槽中相对前移。
- 到达行程终点时，机械释放几何结构允许购物车完全脱离；购物车继续滚动至购物车区域并停住。
- 槽、销、端挡和释放口均封闭防夹；设置低速限位，避免冲击。
- 释放不能由队员在购物车运动中伸手到车轮/夹点附近操作。

**规则澄清是设计冻结前置门：** 必须确认“车辆停止后释放”的动作顺序、购物车在车辆停止后仍有惯性位移是否符合要求、失动槽自动脱离是否构成释放、购物车脱离后由惯性滚动是否符合“行进至购物车区域”。未获得明确答复前，不采购专用机构、不宣称合规、不把该子系统列为已完成。

**失败备选：** 若官方不认可失动/惯性方案，停止该方案并按书面答复重新设计。不得改用队员暗中推车、拉线牵引、磁吸拖动、外部风扇、斜坡或其他外部动力伪装自主返回。

### 3.3 独立卸载装置

采用独立落地式“三工位翻转托盘架”：

- 三个托盘分别对应物品 A、B′、C，托盘尺寸按最终实物制作。
- 每个托盘通过手柄、短连杆和铰链完成抬升/翻转；每个工位可单独操作。
- 底座低重心、宽脚；铰链设止挡，托盘有软挡边；落点在结账区内。
- 装置不连接车辆、不固定在车辆上、不借车辆支撑，也不把车辆上的机构伸入结账区。
- 所有剪切/夹点做护罩或隔离；手柄路径远离手指。
- 物品转移全过程可见；每件物品必须确实从购物车中被拿起并放入结账区，而不是只把购物车倾倒。

### 3.4 订单物品建议

初步道具组合（需队伍确认后定稿）：

| 订单编号 | 订单物品 | 购物区情节 | 选择理由 |
|---|---|---|---|
| A | 原创手工纸艺花束/纸艺雕塑 | 有货，购买 | 可承担风格项目“清单中一件物品的艺术质量”；轻、可见 |
| B | 蓝色纸风车 | 缺货 | 用大号缺货牌明确显示 |
| B′ | 蓝色纸花 | 替代品 | 与 B 同用途/色系，形态明显不同，易展示替代 |
| C | 轻质彩色礼品盒 | 有货，购买 | 尺寸稳定、易放托盘、便于裁判识别 |

以上是创意草案，不是强制商品；最终三件实物必须有形、清晰可见、尺寸与购物车/托盘匹配，且不得有尖锐、易碎、液体、食品过敏或其他安全问题。替代品批准要发生在队伍把 B′作为完成订单物品之前。

## 4. 角色与 8 分钟执行脚本

建议角色（按实际队员人数合并）：
- **车辆操作员：** 乘坐、推进、转向、制动、接收三件物品。
- **购物助理：** 交订单、说明缺货、批准替代、核对结账。

## 5. 风格（50 分）策略

题目要求五项风格：清单中一件物品的艺术质量、音乐的创造性使用、两项队伍自选、四项整体效果。

1. **艺术质量（1–10）：** A 物品采用原创纸艺花束/雕塑；强调造型、比例、色彩和完成度，不只贴标签。
2. **音乐创造性（1–10）：** 队伍自创 10–15 秒“订单节奏”主题，用现场节奏/打击乐器或人声变奏，分别对应交单、替代批准、卸载和回车。不得依赖版权歌曲。
3. **自选项目一（1–10）：** 角色服装与视觉符号：购物助理、操作员、卸载员使用一致色彩编码，体现角色差异。
4. **自选项目二（1–10）：** 舞台道具/视觉设计：订单卡、缺货牌、结账标识和购物车标记形成同一视觉语言。
5. **整体效果（1–10）：** 主题、音乐、艺术物品、服装和机构动作互相呼应；不出现与购物服务无关的长段落。

每个风格项目都要在风格表中清楚标注；具体评分解释以当季手册为准。

## 7. US$160 内部预算与现实可行性

题目官方成本上限是 US$165。团队计划支出目标为 **US$160**，另设 **US$5 价格波动预留**；实际计入成本的项目总额（含预留实际使用部分）绝不得超过 US$165。预留只用于价格上涨、运费/税费变化等，不作为额外采购额度。当前团队从零开始、没有任何实体零件，因此旧预算中“已有/捐赠材料”的假设尚未成立。

**重要结论：** US$160 从零购买一套安全、适配青少年、原创可乘坐的车辆，再加购物车、独立卸载台、连接器、防护和道具，不能被当作可保证实现的全新采购清单。不得为了预算牺牲车架、车轴、转向、制动、防夹或成人专业检查。若无法找到符合要求的捐赠/回收整套结构件，必须向教练提出预算/方案调整，不得冒险拼装。

### 采购冻结条件

- 购物车返回规则未澄清：不购买专用回收机构零件。
- 车辆载荷路径、轮轴、转向和制动未由成人/专业人员审查：不购买互不兼容的散件，不进行载人测试。
- 不能给出完整成本：不下单。
- 全新安全载人系统无法控制在预算内：停止采购并寻求捐赠/预算调整，不得以玩具车、儿童脚踏玩具或家具脚轮代替。

## 8. 测试与验收计划

每个子系统先单独测试，再集成。测试数据必须记录日期、配置、负载、场地、结果、失败原因和修改项。以下次数是团队内部工程门槛，不是题目额外规则。

| Gate / 测试 | 方法 | 内部通过标准 |
|---|---|---|
| G0 规则门 | 核对当季手册、全部官方澄清；提交关键问题 | 所有规则高风险问题有书面答复或明确保守方案 |
| G1 几何门 | 测量标准门洞、车辆包络、购物区、结账区、购物车区 | 全尺寸模型通过且有余量；路径不干涉 |
| G2 结构门 | 成人/专业人员审查材料、承载路径、紧固和稳定性；先静态配重 | 无可见永久变形、裂纹、松动或不稳定；具体载荷由专业人员定 |
| G3 车辆门 | 无乘员配重低速运行，再按批准流程监督测试 | 转向可控、制动可靠、乘员不触地；至少 20 次低速重复无关键故障 |
| G4 连接门 | 带载直行、转弯、停车；反复插销锁止 | 至少 20 次无误脱、无干涉；锁定状态一眼可见 |
| G5 卸载门 | 使用最终三件物品反复操作三个托盘 | 至少 20 轮三件全部进入结账区，无掉落、倾倒或夹伤 |
| G6 回车规则与工程门 | 官方答复后再测试失动/惯性释放 | 规则确认；轻载/满载各至少 20 次进入区域并停住，无人工补推 |
| G7 全流程门 | 完整表演计时和录像 | 连续 5 次模拟均在 8 分钟内，至少 4 次无关键失误，目标 7:15 |
| G8 提交门 | 核对清单、风格表、成本表、外援表、澄清和队伍信息 | 四份要求清单和全部手册要求材料齐全、内容与实物一致 |

### 每次测试/排练前检查

- [ ] 车架、焊缝/连接、轮轴、轴承、紧固件无裂纹、弯曲或松动。
- [ ] 转向限位有效，转向全行程无干涉。
- [ ] 独立制动有效，操作员可触及，停车后车辆稳定。
- [ ] 曲柄、链条、齿轮、皮带和所有夹点护罩固定。
- [ ] 购物车轮子、轴线、载物围边状态正常。
- [ ] 牵引插销、二次保险和可视锁止标记齐全。
- [ ] 失动槽/释放机构复位正确、封闭防夹；若未获规则确认，只能做非比赛台架测试。
- [ ] 卸载台底座稳定，托盘止挡/铰链/手柄无损坏。
- [ ] 三件物品、缺货牌、替代批准标记、订单卡齐全。
- [ ] 赛道边界、队员安全通道和观众隔离明确。
- [ ] 计时器、记录表、工具和清洁用品齐全。

### 立即停止条件

车辆倾斜/结构异响、车架或焊缝变形、轮轴/轮毂松动、制动衰退、转向卡滞、乘员触地、脚/手接近未防护夹点、牵引器误脱、购物车失控、卸载架倾倒或物品飞出，任何一项出现都立即停止测试。青少年不得独自进行载人试验、焊接、切割、钻孔或高能量机构调试。

## 9. 主要风险登记

| 风险 | 等级 | 预防 | 应急 |
|---|---|---|---|
| 载人车架/轮轴失效 | 极高 | 成人/专业审查、可追溯部件、静态配重 | 停止载人测试，重新设计 |
| 制动或转向失效 | 极高 | 匹配系统、冗余检查、低速封闭测试 | 停止运行，不得靠脚刹 |
| 乘员触地/滑落 | 高 | 固定座椅、脚托、低重心 | 调整座舱，复测通过前不排练 |
| 链条/曲柄夹伤 | 高 | 全封闭护罩、机械限位 | 停机并隔离危险区域 |
| 购物车脱钩 | 高 | 双重防脱、插销锁止检查 | 停止流程，重新设计 |
| 回车方案不获认可 | 高 | 提前书面澄清 | 不制作专用机构，按答复重构 |
| 回车偏航/过冲 | 高 | 低能量、限位、轮轴校准 | 降低能量/调整结构，不人工补推 |
| 卸载台倾倒/夹手 | 高 | 宽底座、低重心、夹点隔离 | 停止操作，重新加固 |
| 物品掉落/难识别 | 中 | 托盘适配、颜色/编号 | 换轻质、易识别物品 |
| 超时 | 中 | 7:15 目标、分段计时 | 压缩开场和转场，不跳关键步骤 |
| 超预算 | 中 | 采购冻结门、收据台账 | 停止非关键支出，提交教练决策 |

## 10. 官方澄清清单（按优先级提交）

1. 车辆原创性：队伍是否可以在商业零件基础上制作原创推进/行进系统？哪些现成底盘或主要结构会被认为不满足原创要求？
2. 购物车释放：B7g5 与 B11 对车辆停止、购物车越过起始线垂直平面和释放的顺序，是否应按“购物车越线后车辆停止并释放”理解？
3. 失动/惯性回车：车辆停止时购物车在封闭失动槽内因惯性继续移动、到槽端自动完全脱离，是否构成题目要求的释放并行进？
4. 购物车脱离后仅靠自身剩余动量滚动到购物车区域，是否满足要求？是否必须有独立驱动？
5. 自动机械释放是否允许，还是必须由队员手动操作释放？
6. 购物车在完全脱离车辆前后，是否允许与失动槽/导向件接触？何时开始判定“释放”？
7. 购物车区域的边界与“至少一个接地点在区域内”的判定方式是什么？是否必须完全停止后再判定？
8. 结账区边缘的独立卸载架是否可放置在赛道边界附近？是否允许装置底座接触地面胶带区域？
9. 购物物品是否可为队伍自制纸艺/轻质道具？是否有尺寸、重量、材料或安全限制？
10. 标准门口净宽/净高是否由赛事统一定义？是否需带购物车同时通过？
11. B7g3 中维修后返回故障前相同位置与方向的判定，是否影响正常调节或机构复位？
12. 当季成本规则如何计入捐赠/借用材料、旧零件、工具、服装、可重复使用道具和运输费用？

提交时逐条引用题目段落号，保存官方原文答复及日期。题目文件指出澄清截止日期为 **2027-02-15**；截止后仍需持续查看官方发布的澄清。
