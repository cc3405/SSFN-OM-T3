# 18 · 载人车辆工程布置图（概念冻结版 Rev A）

> **图纸等级：CONCEPT / NOT FOR CONSTRUCTION。** 本文件给出队伍下一步应采用的总体布置、视图、尺寸基准和审查接口，不是可直接切割、焊接、钻孔或组装的施工图。由于目前没有实际操作员人体数据、场地门洞实测值、经过确认的零件型号/额定值，也没有合格工程人员签字，**本车保持 NO-RIDE，禁止真人试乘**。

## 0. 本版设计决定

选择**低坐姿三轮“蝌蚪式”布局（前双转向轮、后单驱动轮）**作为唯一优先研究概念：

- 前方两轮负责转向；后方单轮负责驱动。
- 操作员采用半躺/低坐姿，双脚位于封闭脚踏区，双手负责转向与制动；行进中任何身体部位不得触地。
- 人力推进候选为前置脚踏曲柄，经封闭传动链路驱动后轮。传动比、链线、张紧、护罩和失效模式须由成人工程人员设计审查。
- 车辆后部中心线设置购物车牵引接口；购物车保持独立、可拆卸，不能遮挡制动或碰撞操作员。
- **不在本版设计自制承载车架、转向节、轮轴、制动器或轮毂。** 这些安全关键件必须采用可追溯、匹配且有制造商额定资料的整套系统；任何改装是否允许及是否影响额定能力须由制造商/工程人员确认。
- 题目要求车辆的行进方式和/或推进方式来自队伍创意与制作。此三轮布局本身并不自动证明原创性；队伍必须设计并制作可明确展示的原创推进/行进子系统，并在动工前向官方澄清其是否满足原创性要求。若原创性与安全无法同时满足，暂停该路线，向教练重新选型，不得以不安全自制底盘凑原创性。

**为什么选三轮而不是原四轮手摇车：** 前双轮可形成明确的转向/制动端，后单轮可形成清晰驱动链路；低坐姿有利于降低重心。它仍有侧翻、转向过度、牵引摆振和制动失效风险，不能仅凭布局判断稳定或安全。

## 2. 尺寸表：采用人体与场地基准，不虚构固定尺寸

| 编号 | 尺寸/参数 | 定义与确定方法 | 冻结前要求 |
|---|---|---|---|
| W-01 | 车辆最大外宽 | 前轮、轮胎、把手、护罩和装饰中最宽者的外包络 | 实测比赛“标准门口”净宽；车辆外宽必须留有明确余量，不能擦门通过 |
| L-01 | 车辆总长 | 前轮最前点至牵引接口最后点 | 以转弯包络、购物车连接和赛道布置实测 |
| WB-01 | 轴距 | 前轮接地点参考线至后轮接地点 | 由匹配底盘/制造商几何确定，不自行猜值 |
| T-01 | 前轮轮距 | 左右前轮接地点中心距离 | 由底盘制造商几何与稳定性分析确定 |
| H-01 | 座椅高度 | 地面至座椅承载面的高度 | 结合重心、离地间隙、操作员上下车和结构设计确定 |
| E-01 | 脚踏可调范围 | 座椅参考点至曲柄轴/脚踏位置的可调范围 | 必须覆盖实际操作员腿长，脚部全程不触地、不碰轮胎 |
| C-01 | 操作员净空 | 头、膝、肘、脚与车架/转向/传动件的最小间隙 | 以实际操作员穿比赛鞋服坐姿实测，所有行程均不干涉 |
| G-01 | 离地间隙 | 车辆最低固定部件至地面 | 结合赛场地面、转弯侧倾、脚踏运动包络确定 |
| HITCH-01 | 牵引点高度 | 地面至牵引接口中心 | 由购物车接口和车辆稳定性共同确定；不得把上拔/侧向载荷传入薄弱构件 |
| CART-01 | 购物车包络 | 购物车最大宽、高、长及转弯扫掠区 | 与车辆组合后实测通过门洞和赛道转弯 |
| BRAKE-01 | 制动距离/保持能力 | 指定载荷、速度、地面条件下的停车表现 | 由工程人员制定测试程序与验收限值，不在纸面臆定 |

**尺寸冻结原则：** 先测量实际操作员和场地，再选定经过验证的底盘/轮组；不能先画一个漂亮尺寸再要求青少年身体去适应。门洞余量、转弯包络和制动性能必须用实际整车（含购物车）验证。

## 3. 安全关键接口（本文件不指定加工规格）

| 接口 | 必须提供的资料 | 禁止做法 |
|---|---|---|
| 车架/座椅 | 制造商载荷资料或专业计算；载荷路径；固定点检查 | 未知管材/薄板拼接后直接载人 |
| 轮组/车轴/轴承 | 型号、额定载荷、轴径、轮毂兼容性、锁止方式 | 家具脚轮、玩具轮、未知承载轮、螺纹杆充当车轴 |
| 转向 | 转向几何、机械限位、全行程间隙、连接防松 | 拉绳转向、松旷连杆、无止挡转向 |
| 制动 | 与底盘匹配的制动器/控制器、制造商说明、制动测试记录 | 脚蹭地、木块摩擦、传动阻力、临时夹具 |
| 推进 | 原创性说明、传动路线、护罩、断链/卡滞失效分析 | 裸露链条/齿轮、脚部靠近夹点 |
| 牵引 | 额定牵引接口、垂直/侧向载荷审查、双重防脱 | 把购物车挂在座椅、转向杆或未经核算的薄壁构件上 |

## 4. 设计冻结前必须拿到的工程输入

1. 实际操作员：身高、体重、腿长、坐姿尺寸、鞋码；由教练/监护人私下记录，仅向设计/安全负责人提供必要数据。
2. 赛场：标准门口实际净宽/净高、地面材质、赛道图 A 对应区域尺寸；向场地主任确认。
3. 底盘候选：制造商、型号、说明书、额定载荷、允许的改装范围、轮组/制动匹配资料。
4. 原创推进系统：队伍自行提出的机构原理图、能量/力流、失效安全分析、零件来源；先取得教练和官方规则意见。
5. 购物车：车体尺寸、载荷、轮子直径/轴线、满载重心、连接点位置。
6. 成人工程审查：至少包括结构、车辆动力学/稳定性、制动、转向和夹点防护。没有适任成人审查人，不进入载人设计冻结。

## 5. 验证顺序（任何一步失败即停止）

- **V0 规则核验：** 车辆推进/行进原创性和底盘可用范围得到教练确认；必要时向官方澄清。
- **V1 人体工学模型：** 用纸板/泡沫/无承载模型验证座椅、脚踏、把手、上下车和视野；不得坐在未验证的承载框架上。
- **V2 零件文件审查：** 核对每个承载、转向、制动部件型号及制造商额定资料；不匹配即淘汰。
- **V3 无人静态测试：** 由成人工程人员制定固定配重、支撑、隔离和检查方法；不得让人坐在测试车上。
- **V4 无人动态测试：** 仅在专业人员批准的封闭测试区使用固定配重和远离人员的测试方法，检查直行、转向、制动、牵引摆振。
- **V5 受监督载人测试：** 仅在 V0–V4 全部书面通过后，由合格成人专业人员现场监督，使用逐级低速、空旷隔离场地和明确停止方案。青少年不得独自试车。
- **V6 复测与记录：** 每次配置变更都重新评估；出现裂纹、松动、制动衰退、转向卡滞、异常摆振或永久变形立即停用。

## 6. 设计取舍与风险

| 设计选择 | 好处 | 仍需控制的风险 |
|---|---|---|
| 前双轮转向、后单轮驱动 | 传动路径清晰，脚踏与转向职责分离 | 转弯侧翻、前轮制动分配、牵引摆振 |
| 低坐姿 | 有利于降低重心 | 视野、上下车、紧急离车和脚部净空 |
| 后中心线牵引 | 减少左右偏置 | 拖车载荷影响后轮抓地、制动和转向稳定性 |
| 独立购物车 | 满足可拆卸购物车概念 | 释放时序及惯性回车方案仍须官方澄清 |
| 原创推进子系统 | 有机会满足题目原创推进/行进要求 | 设计越复杂，夹点、失效和预算风险越高 |

## 7. 本版不允许被误用的事项

- 本图不是载人车架的加工图；没有材料牌号、壁厚、焊缝、螺栓等级或轴承选型，是有意留空，须由合格工程人员根据实际载荷确定。
- 不得根据示意图自行购买零件、焊接车架或让青少年进行载人测试。
- 不得宣称该布局已经满足题目原创性、标准门洞、稳定性或制动要求。
- 本题 B3 的 8 分钟包含赛场布置、风格表演、解题和承重测试；承重测试按当季活动手册/裁判指令执行，不能自行用危险载人动作代替。
- 购物车返回的惯性/失动槽方案尚未得到官方认可；不得把它画成已批准的功能机构。
