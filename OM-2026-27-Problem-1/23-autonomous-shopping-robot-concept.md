# 23. 自动寻路与展台取货机械臂——独立实验模块概念方案

> **状态：概念设计 / 待选型 / 待核价 / 未制作 / 未测试 / 不属于当前比赛基线。**
>
> 本文件记录团队提出的 A 方案：机械臂安装在独立循迹小车上。小车沿地面路线自动转弯，到达商品展台后停车，机械臂从展台抓取商品并放入后方购物车。
>
> 本模块不得与载人比赛车辆的推进、转向、制动或承载系统混为一体。未经赛事官方书面确认，不得将其视为符合 OMER 题目要求的比赛功能。

## 1. 目标与范围

只实现以下闭环：

1. 小车沿预先铺设的地面路线行驶；
2. 路线包含简单弯道，小车能自行修正方向并通过；
3. 小车到达展台前的固定停车标记后停止；
4. 小车停稳后，机械臂自动从固定展台位置夹取一个轻量商品；
5. 机械臂将商品移动到后方购物车上方并松开；
6. 机械臂回到安全收纳姿态，系统给出完成信号。

**明确不做：**摄像头视觉识别、AI物品识别、SLAM地图构建、复杂动态避障、多目标自主规划、语音控制、移动中抓取，以及在载人车辆行驶时操作机械臂。

## 2. 系统构成

### 2.1 自动寻路底盘

- 低速、低重心的两轮差速实验底盘，带万向支撑轮；
- 红外循迹传感器阵列识别地面胶带路线；
- 双路电机驱动器分别控制左右轮；
- 微控制器读取传感器并调节左右轮速度；
- 电池独立供电，设置实体电源开关；
- 终点使用明显的停止标记，建议用独立地面标记传感器或可重复识别的加宽线段触发停车。

弯道逻辑采用简单循迹控制：检测到路线偏向左侧时降低/调整左轮速度并修正车头；偏向右侧时反向修正。先验证直线、单个90度弯、连续弯，再增加完整路线。路线、车速和传感器高度必须固定并记录。

### 2.2 机械臂与夹爪

- 建议从2–3自由度桌面级机械臂开始；
- 舵机驱动肩部/肘部和夹爪，避免一开始采用复杂多关节结构；
- 夹爪使用软质防滑垫，商品采用轻量、尺寸固定、无尖锐边缘的演示物；
- 机械臂动作采用预设位置序列，不依赖视觉识别；
- 机械臂安装支架固定在小车底盘上，抓取时小车必须制动/停车；
- 设置机械臂运动范围限位，避免碰撞展台、购物车、车轮和人员。

### 2.3 展台与购物车接口

- 展台商品位置固定，提供明确的抓取边缘或抓取区域；
- 购物车停放位置固定，车厢开口与机械臂放置位置对齐；
- 展台与购物车相对位置、商品尺寸、抓取高度和放置高度均需测量并写入调试记录；
- 购物车在抓取实验中保持静止，避免机械臂放置时购物车移动；
- 机械臂不得伸入人员可能同时操作的狭窄夹点。

## 3. 自动动作状态机

| 状态 | 动作 | 转移条件 |
|---|---|---|
| S0 待机 | 电机停止，机械臂收回 | 启动指令 |
| S1 循迹 | 沿胶带路线低速前进 | 检测到终点标记 |
| S2 定位停车 | 电机停止并保持车身静止 | 停车稳定、位置检查通过 |
| S3 伸臂 | 机械臂移动至展台抓取点 | 到达预设位置 |
| S4 夹取 | 夹爪闭合 | 达到预设夹持动作 |
| S5 抬升转移 | 机械臂抬起并转向购物车 | 到达放置点 |
| S6 放货 | 夹爪打开，商品落入购物车 | 打开动作完成 |
| S7 复位 | 机械臂回到收纳姿态 | 复位完成 |
| S8 完成 | 发出灯光/声音/文字完成信号 | 人工复位 |

若循迹丢失、停车标记未识别、机械臂动作受阻或商品掉落，系统应停止电机并进入故障状态；不得自动继续盲目动作。应保留实体急停/断电手段。

## 4. 低成本实施路线

采用分阶段制作，避免一次性购买整套复杂系统：

1. **阶段一：循迹底盘。**先只购买底盘、电机驱动、红外循迹传感器、控制板和电池，完成直线与简单弯道测试。
2. **阶段二：桌面机械臂。**在固定底座上测试抓取与放置，确定实际可达范围和商品重量上限。
3. **阶段三：车载集成。**制作独立安装支架，把机械臂固定在循迹底盘上；测量展台和购物车相对位置。
4. **阶段四：自动顺序。**把终点检测、停车、抓取、放置、复位串成状态机。
5. **阶段五：可靠性验证。**进行重复循环测试，记录循迹成功率、抓取成功率、掉落次数、电池续航和故障模式。

优先使用固定位置与固定尺寸商品，避免为视觉识别、机械臂更多自由度和复杂路径规划付费。

## 6. 与 OMER 比赛方案的边界

- 本模块是独立的无人实验小车，不是载人比赛车辆，也不得替代原创载人推进/转向系统。
- 比赛题目对购物、缺货替代审批、结账前向操作员交货、结账处卸货装置等有明确流程。本模块自动从展台取货并放入购物车，可能改变队员角色和物品交接方式。
- 在将本模块用于正式比赛前，必须向赛事官方书面确认：自动小车是否允许进入购物区、机械臂自动抓取是否允许、是否影响“shopping assistant”与操作员交接要求、是否与购物车连接/移动规则冲突，以及自动设备是否属于题目允许的车辆/装置范围。
- 在收到明确答复前，比赛基线仍采用已记录的人工购物流程；此实验模块不得计入已完成的比赛功能或已验证的得分能力。
- 本模块不得连接或控制载人车，不得在载人车运动时伸臂或抓取。

## 8. 当前未决问题

- 商品最大质量、尺寸、形状和表面材质；
- 展台高度、抓取点坐标、购物车高度与相对距离；
- 机械臂实际负载、工作半径和舵机堵转电流；
- 底盘尺寸、车速、地面材质、路线宽度和弯道半径；
- 控制板、电源和驱动器的兼容性；
- 该模块是否仅作课外演示，或未来申请纳入比赛；
- 完整BOM报价和预算来源。

## 9. 当前结论

A方案在概念上可拆成“低速循迹到站”和“固定点机械臂抓放”两个容易逐步验证的子任务。为了控制成本和风险，应先分别验证，再集成；不购买视觉系统，不做复杂自主导航，不在移动中抓取。
