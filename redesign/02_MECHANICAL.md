# 02 — 机械系统设计

## 1. 载人车辆：低重心脚踏四轮车

### 1.1 结构布局
- 车架：矩形木/金属混合底架；优先采用可检查的螺栓连接，关键受力节点加三角撑。
- 车轮：四轮布置，前轮转向、后轮固定驱动；轮距与轴距以驾驶员重心和转弯半径实测确定。
- 座椅：固定在车架纵梁上，靠背和侧向支撑防止驾驶员在转向时滑移。
- 推进：左右两根独立脚踏摆杆分别通过链条驱动后轴上的单向离合/棘轮；驾驶员交替下压左右踏板，回程弹簧将踏板复位，单向离合在回程空转，确保后轴持续朝前转动。脚掌始终留在车载踏板上，不接触地面。
- 防护：链条、棘轮、回位弹簧和摆杆夹点全程加护罩或防夹结构。
- 转向：前轮转向节 + 横拉杆；转向角设机械限位，转向拉杆使用防松螺母/开口销。
- 制动：独立脚/手制动作用于驱动后轴或后轮；制动拉索断裂风险需通过赛前检查降低。

### 1.2 传动建议
采用两根自制脚踏摆杆、两条链条、两组单向离合/棘轮和后轴链轮。每次下压行程将摆杆的往复运动转换为后轴单向旋转；回程弹簧只负责复位，不反向驱动车轮。左右踏板交替输出，避免单次踩踏后车辆停顿。初始踏板行程和齿比从低速高扭矩开始，先保证满载起步、平顺性与可控停止，再逐步提高速度。禁止为追求速度牺牲制动距离和转向稳定。

### 1.3 初始几何（打样参数，必须实测调整）
| 参数 | 初始目标 | 选择理由 |
|---|---:|---|
| 总宽度（含装饰） | ≤700 mm | 标准门口通行留余量 |
| 车架长度 | 1,200–1,400 mm | 留出脚踏/座椅/转向空间 |
| 轮距 | 650–700 mm | 提高横向稳定性 |
| 座面高度 | 250–350 mm | 降低重心 |
| 车轮直径 | 200–300 mm | 兼顾滚动阻力与结构尺寸 |
| 离地间隙 | ≥50 mm | 避免地面接缝刮碰 |

以上不是题目规定尺寸。最终尺寸应以实际驾驶员、车轮、门框和赛场地面验证为准。

### 1.4 安全设计
- 车架按驾驶员实际质量的至少 2 倍静态载荷进行内部验证；这只是工程验证目标，不是官方载荷标准。
- 逐级加载，不允许人员站在可能断裂的车架上做首次测试。
- 制动测试先用配重，再由成人/队员在低速封闭区域验证。
- 车轮、链轮、曲柄、转向节、拖车连接点设置护罩或防夹间隙。
- 车辆失控时驾驶员可立即停止踩踏并制动；无电池、无电机、无外接动力。
- 装饰不得遮挡驾驶员视线、制动、转向或裁判观察。

## 2. 购物车与牵引接口

### 2.1 连接
- 购物车前端通过刚性牵引杆连接车架后横梁。
- 主连接采用可见的快拆销；保险卡扣防止振动脱落。
- 牵引杆长度应保证转弯时购物车不撞击车辆后轮。
- 连接/释放动作必须可从驾驶位完成，且不得要求队员在车辆移动时靠近车轮。

### 2.2 三件商品固定
- 篮筐内设置三个颜色/形状不同的软托位，分别标记 A/B/C。
- 商品外壳采用轻质材料，内部加配重时固定牢靠。
- 软托位不遮挡商品主体，确保裁判可识别每一件物品。
- 替代品与原缺货物品外形明显不同，避免误判为原商品。

## 3. 购物车“星轨归位”机构（需官方澄清）

### 3.1 机构概念
购物车自身安装封闭式弹性储能卷筒、两轮差速传动和凸轮换挡机构。开始前由队员在准备阶段手动预储能并锁止。车辆牵引期间，驱动机构通过单向离合与车轮隔离，不产生明显拖滞。购物车释放时，快拆动作同步触发两阶段凸轮：第一阶段差速驱动左右轮反向转动，使购物车低速原地转向约 180°；第二阶段切换为双轮同向驱动，推动购物车朝右下购物车区域行进。第二阶段的转向凸轮将前端导向角设为朝向右下购物车区域的预设角度（样机初始可调范围 15°–30°，最终以图 A 场地实测为准）；驱动轮同时带动“星轨”转盘和轻质反光飘带。

### 3.2 安全与限速
- 弹性元件必须置于封闭护罩内，避免断裂回弹伤人。
- 设置可调摩擦制动/滑差离合，防止空载或低摩擦地面上速度过快。
- 设置机械行程止挡和独立紧急断能方式。
- 不能依赖地面坡度；必须在平整地面测试。
- 释放前购物车由主牵引销保持连接；任何弹性动作不得让购物车提前移动。
- 购物车穿过起始线所在垂直平面后，车辆停止并保持在起始线上或起始线之外，直至购物车完全静止在购物车区域。
- 释放后无人追推、无人牵引，不能用隐藏线缆从场外拉动。

### 3.3 必须完成的试验
1. 空载、半载、满载各 20 次。
2. 不同地面摩擦条件各 10 次。
3. 释放距离、终点位置和车辆停止位置均需记录；每次购物车都必须完全停稳，且车辆始终保持在起始线上或起始线之外。
4. 统计越界、偏航、未启动、提前启动、弹性元件损坏。
5. 只有连续 30 次无安全故障且成功率达到团队设定门槛后，才可纳入正式演出。

### 3.4 合规备选
如官方澄清不支持购物车自带储能驱动，立即停用弹性动力概念。备选方向为采用无动力的滚动惯性回归：车辆在满足 B11 的越线和停车时序下，以可控速度和路线使购物车在释放时朝购物车区域运动，并以车轮转盘、反光飘带强化视觉效果。该备选必须在实际赛场地面和完整路线下证明释放后的动量足够；不得擅自用场地坡度或队员暗中推动。

## 4. 独立卸货装置：“轨道升降臂”

### 4.1 构成
- 独立底座：宽基座 + 斜撑，放在结账区域边缘，不与车辆连接；采用折叠铰链和快锁销，布场时展开，目标 15 秒内完成锁定。
- 立柱/横梁：形成门架，保证升降滑架垂直运行。
- 升降：手摇绞盘 + 绳索/滑轮，带动三格承托篮升降。
- 回转：水平转臂在 0°（购物车上方）与 90°（结账区上方）之间转动。
- 锁止：两个角度都有定位孔和插销，禁止靠操作者手臂持续承重。
- 卸货：到达结账位置后，操作者拉动释放柄，三格承托篮向结账台倾转，三件商品落入有软垫边沿的结账托盘。

### 4.2 操作顺序
1. 购物车停入结账位并制动/固定。
2. 操作者将回转臂锁定在 0°。
3. 放下承托篮，三个软托分别套住三件商品。
4. 手摇绞盘升起承托篮，直至离开购物车篮筐。
5. 操作者旋转转臂至 90°，插入定位销。
6. 缓慢下降/翻转承托篮，三件物品进入结账区域。
7. 购物助理逐项点验；操作者复位空篮。

### 4.3 工程细节
- 承托篮应针对三件道具做形状定位，减少夹持调节时间。
- 绞盘必须有自锁或棘轮，松手不得下坠。
- 回转锁销应可视、可听确认；未锁止不得提升。
- 绳索使用额定强度有余量的成品绳，端部采用可靠绳夹/结扣并做拉力验证。
- 底座不得妨碍车辆路线、购物车回归路线或结账区评分视线。
- 所有夹点、剪切点加护罩或保持安全间隙。

## 5. 系统级检查清单
- [ ] 车辆完全自成一体，无外部动力。
- [ ] 乘员坐稳，脚踏全程不触地。
- [ ] 车宽实测通过标准门口。
- [ ] 制动、转向、链条护罩、结构紧固通过检查。
- [ ] 购物车与车辆连接可靠，满载不碰轮。
- [ ] 卸货装置独立于车辆，三件物品都能被举起并进入结账区。
- [ ] 购物车释放发生在正确的起始线时序之后。
- [ ] 购物车静止后至少一个接地点位于购物车区域。
