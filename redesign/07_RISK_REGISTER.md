# 07 — 风险登记与降级策略

| 风险 | 概率/影响 | 预防措施 | 比赛日降级方案 |
|---|---|---|---|
| 购物车弹性驱动被质疑不符合题意 | 中/极高 | 尽早提交官方澄清；保留原理图和工作方式说明 | 不使用未获认可的储能驱动；切换到已确认合规的回归方案 |
| 车辆结构断裂/座椅松动 | 低/极高 | 配重静载、疲劳测试、关键节点双重紧固 | 停止乘坐演示；不得现场临时用手推乘员车 |
| 制动失效 | 中/极高 | 独立制动检查、低速制动距离测试、备用拉索 | 不允许载人行驶，安全优先 |
| 链条夹手/卷入衣物 | 中/高 | 全封闭链罩、服装束紧、禁触运动件 | 停止运行并隔离故障部件 |
| 购物车转弯碰撞车辆 | 中/中 | 牵引杆长度、转弯半径和路线排练 | 降低速度、放大转弯半径 |
| 物品在运输中掉落 | 中/中 | 三格托位、软带固定、颠簸测试 | 停车后按规则维修；车辆需回到故障前相同位置和方向 |
| 替代品未被清晰批准 | 低/高 | 助理固定台词、驾驶员明确回应、订单板显示状态 | 重新清晰表达批准；不可直接把替代品当原物 |
| 卸货绞盘下坠/转臂未锁 | 中/高 | 自锁绞盘、机械定位销、承托篮限位 | 放弃快速动作，缓慢复位；禁止人员进入悬载下方 |
| 卸货时间超时 | 中/中 | 商品标准化、一次性三格夹持、重复演练 | 删除非必要对白，不删三件物品卸货 |
| 购物车回归偏航/越界 | 中/高 | 低速限位、地面实测、路线对齐 | 使用官方澄清允许的低风险回归替代方案 |
| 总时间超过 8 分钟 | 中/高 | 7:20目标、10次整场演练 | 删除非评分台词/舞蹈，保留全部题目动作 |
| 成本超过 $165 | 中/极高 | $135目标、$30余量、每次采购记账 | 取消装饰升级，替换高成本材料 |
| 场地与预演不同 | 中/中 | 赛前联系赛场主任，准备可调脚轮/限位 | 使用保守速度与较宽路线，不依赖固定地面条件 |

## 故障处理原则
1. 安全优先于得分和时间。
2. 车辆行进中不得由队员触地帮助推进；任何维修后必须回到故障前相同位置和方向。
3. 不通过隐藏人员、隐藏线缆、场地坡度或外部动力补救。
4. 不确定规则解释时按更严格、更保守的方式执行，并向裁判/官方澄清渠道确认。
