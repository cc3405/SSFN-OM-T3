# Group II Clean-Slate Design — OMER Shopping Service

> 依据：`D5/1111111-main/1.md`（2026–2027 长期题1）。目标组别：II；团队规模：7人。
> 本目录是独立的全新方案，不沿用仓库中旧方案的机构、控制逻辑、剧本或进度假设。

## 一句话方案

**“星际补给站 / ORBITAL MARKET”**：一辆由乘员脚踏驱动的原创四轮低重心车辆牵引购物车完成采购；购物助理批准缺货替代品；一个与车辆完全分离的手摇升降—回转卸货架将三件物品整体转移到结账区；连接的购物车穿过起始线所在垂直平面、车辆停止后释放购物车，购物车利用自身预储存的弹性机械能回到购物车区域，并驱动醒目的“星轨”转盘。

## 设计优先级

1. 规则完整性与无争议性高于炫技。
2. 每个评分点都要有可见动作、明确台词/提示和可重复验证。
3. 关键动作采用机械限位、正向锁止和人工确认；不依赖无线通信、视觉识别或复杂固件。
4. 以可回收/二手材料为主，按保守价值计入成本；预算目标 $135，保留 $30 余量。
5. 所有结构必须先完成载荷、安全、门宽、地面适应和 8 分钟整场演练。

## 重要的规则边界

- 车辆必须由一名或多名乘坐其上的队员操作；车辆行进时，乘员完全由车辆支撑且不得接触地面。
- 购物车随车辆行进、承载物品并用于结账；车辆与购物车的连接方式可由队伍设计。
- 卸货装置必须原创、自制且不能连接到车辆。Group II 可由队员直接人力操作。
- 购物车回归必须在结账后、连接的购物车穿过起始线所在垂直平面、车辆停止后进行；购物车最终静止时至少一个接地点位于购物车区域。
- 8 分钟包含布场、风格表演、解题和承重测试；所有活动必须在时间结束前停止。
- 165 美元上限按题目和当年活动手册的成本规则核算。此处预算是工程估算，不替代正式成本表。

## 关键待确认事项

1. 向官方提交澄清：购物车释放后，是否允许使用安装在购物车自身、在开始前由队员手动预储能的弹性机械驱动装置，使购物车自行滚回区域？在获得答复前，不把该机制视为已获官方认可。
2. 向当地赛场主任确认实际地面摩擦、起始线/购物车区域位置、结账区大小和场地可用尺寸；题目明确这些场地信息应向赛场主任询问，而非作为题目澄清。
3. 对照完整 2026–2027《头脑奥林匹克活动手册》核验一般规则、成本估值、外部援助、队籍标志和安全要求，并持续查看官方澄清更新。
