# 03 — 8分钟表演剧本与调度

## 1. 舞台语言

主题：**“星际补给站：最后一份生命补给”**。

视觉主色：深蓝、银色、荧光绿。所有色彩仅作艺术包装，不遮挡结构和商品。音乐由队员现场创作：节奏口令、容器敲击、脚踏机械声和三件商品入托的音效组成；不依赖播放设备或现成歌曲。

## 2. 逐分钟调度（目标 7:20，预留 40 秒）

| 时间 | 动作 | 负责队员 | 对应题目要求/评分可见点 |
|---|---|---|---|
| 0:00–0:25 | 快速布场；车辆/装饰在起始线后，购物车接地点在购物车区域；其他队员和道具在准备区 | 全队 | B7a、C；不能提前越线 |
| 0:25–0:55 | 旁白建立月面温室危机；购物助理交付三项订单卡 | 旁白、助理、驾驶员 | 创意、整体质量；助理呈现清单 |
| 0:55–1:15 | 驾驶员确认牵引销，坐上车辆，脚置踏板，出发 | 驾驶员 | 原创车辆、乘员不触地 |
| 1:15–2:25 | 车辆牵引购物车进入购物区；两名拣货员把生命种子舱和月泉水瓶放入对应托位 | 驾驶员、拣货员 | 三件商品采购过程可见 |
| 2:25–3:05 | 驾驶员发现太阳能芯片缺货；助理展示缺货位与风能晶核，清晰说明替代并获得批准 | 助理、驾驶员、拣货员 | 替代批准；清单/替代评分 |
| 3:05–3:50 | 风能晶核放入第三托位；驾驶员确认三件齐全，牵引购物车驶向结账区 | 拣货员、驾驶员 | 完成购物、购物车随车推进 |
| 3:50–4:10 | 车辆停在卸货装置工作位；购物车固定 | 驾驶员、卸货员 | 进入结账流程 |
| 4:10–5:15 | 独立卸货架依次完成套篮、升起、回转、锁止、倾倒；三件商品清楚进入结账区 | 卸货员 | 卸货装置功能与创造性 |
| 5:15–5:45 | 助理逐项核对三件物品，明确宣布替代品获批且订单准确 | 助理、旁白 | 助理检查准确性 |
| 5:45–6:50 | 驾驶员继续牵引购物车通过起始线垂直平面；车辆停稳后从驾驶位拉动释放柄；购物车自行回归 | 驾驶员、旁白 | 购物车释放、回归和视觉效果 |
| 6:50–7:20 | 购物车静止后确认至少一个接地点在购物车区域；全队完成主题收束并发出完成信号 | 助理、旁白、全队 | B7g5、完成信号；留出时间余量 |

## 3. 台词关键句（必须明确、不可含糊）

**助理交单：**
“星际补给订单：生命种子舱、月泉水瓶、太阳能芯片。三件都要送到结账台。”

**缺货与替代：**
“太阳能芯片缺货。我们提供风能晶核作为替代品。你是否同意用风能晶核替换太阳能芯片？”

驾驶员/顾客必须明确回答：“同意，批准替代。”

**结账核验：**
“生命种子舱，一件；月泉水瓶，一件；风能晶核，一件。替代已获批准，订单完整准确。”

**购物车回归：**
“订单已结账，车辆和购物车越过起始线。现在释放购物车，返回停靠区！”

## 4. 现场音乐设计
- 开场：全队用三拍口令“装载—确认—出发”建立主题节奏。
- 采购：拣货员每放入一件物品，敲击对应的轻质音板/容器，形成三音动机。
- 缺货：音乐短暂停顿，助理用单独音型提示“缺货”；批准后用新音型回应“替代成功”。
- 卸货：绞盘节奏与队员原创节拍同步；三件商品落入结账区时完成三拍收束。
- 回归：购物车星轨转盘旋转时，队员用声音模拟“归航”渐弱节奏。

音乐必须由团队原创编排；机械声可以成为节奏的一部分，但不能盖过购物助理的关键台词。

## 5. 完成信号
使用清晰、事先写入解题明细表的口头信号：“补给完成，星际归航！”并同时举起订单板。信号不得在购物车尚未静止或任何必需动作尚未完成时发出。

## 6. 时间纪律
- 7:20 是目标结束时间，不是硬性规则；8:00 为绝对停止点。
- 排练时若任一段连续三次超时，先删减非评分台词/装饰动作，不删规则动作。
- 发生机械故障时，优先保证安全；不允许为了赶时间而让队员触地推动乘坐车辆或提前释放购物车。
