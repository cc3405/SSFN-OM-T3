# D5 旧版资料（归档，不作为当前固件）

本目录保留最初赶工版本的资料，供查阅原先的任务想法、机械草图和可复用算法。旧 `.ino` 文件面向 Arduino Nano/ATmega328P，包含 TB6612FNG、RF24、OLED、MPU6050 等旧硬件，**不能直接作为 ESP32-S3 固件编译或接线依据**。

当前主控统一为 ESP32-S3 N16R8。当前固件入口是：

- [ESP32-S3 固件](../firmware/esp32_s3/esp32_s3.ino)
- [固件接线/环境说明](../firmware/esp32_s3/README.md)
- [GPIO 与电气安全](../docs/ESP32S3_PINMAP.md)

旧资料中的 Nano 引脚编号、电机驱动器、5V 信号连接、I2C/SPI 接线和库不能直接迁移。即使只复用算法，也必须重新审核引脚、电压、电流、失效安全和官方规则。旧版购物车主动回位、复杂机械臂和无线多板结构均不属于当前方案的默认要求。
