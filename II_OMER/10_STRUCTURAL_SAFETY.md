# 10 · 结构载荷路径与安全设计审查

> 本文件定义必须完成的工程验证，不是结构认证。当前资料缺少驾驶员最大质量、购物载荷、材料牌号、焊缝等级、轴承型号和制动器额定值，因此不得宣称结构安全系数已满足要求。

## 1. 载荷工况清单

| 工况 | 作用 | 必须检查 |
|---|---|---|
| S1 静态满载 | 驾驶员 + 车辆自重 + 购物车牵引载荷 | 车架弯曲、座椅支座、轮轴、轮胎额定载荷 |
| S2 起步/停止 | 传动扭矩与纵向惯性 | 曲柄座、链轮座、后轴键/联轴器、牵引耳板 |
| S3 急停 | 制动力和乘员前向惯性 | 制动座、座椅/靠背、脚托、紧固件 |
| S4 转弯 | 横向加速度及偏载 | 轮距、重心高度、转向节、横拉杆、侧翻裕度 |
| S5 单轮不平 | 车架扭转 | 横撑、焊缝、轴承座安装面 |
| S6 购物车冲击 | 拖挂间隙、牵引杆摆动 | 双剪切销、保险销、车端耳板 |
| S7 卸货台倾覆 | 托盘偏载与操作力 | 底座、立柱斜撑、防滑脚、锚固/压载需求 |

## 2. 载荷输入必须实测/确认

设计前填写：驾驶员最大质量 m_r = ____ kg；车辆质量 m_v = ____ kg；购物物品与购物车质量 m_c = ____ kg；目标最大速度 v = ____ m/s；最大制动减速度 a_b = ____ m/s²；重心高度 h = ____ mm；轮距 b = ____ mm。未知数据不得用猜测值替代。

基础关系：
- 静态总重 W = (m_r + m_v + m_c)g。
- 急停纵向惯性力 F_x = (m_r + m_v + m_c)a_b；载荷分配需按轴距、重心位置计算。
- 转弯横向惯性力 F_y = m_total v²/R；R 为实测转弯半径。
- 简化侧翻临界条件需比较横向加速度与 g·(b/2)/h；该模型忽略轮胎变形、悬架、地面不平和动态载荷转移，只能用于早期筛查。
- 制动距离理想估算 d = v²/(2a_b)，实际必须在比赛地面、满载和不同速度下实测。

## 3. 结构设计审查点

### 车架与座椅
- 先确认材料是钢或铝，不可在未重新计算/工艺评估时互换。记录材料牌号、壁厚、供应商和批次。
- 座椅载荷必须经横梁/纵梁传入车架主结构；避免只把座椅固定在薄壁局部。
- 座椅、靠背、侧向支撑、脚托及扶手均须检查紧固件防松与边缘圆角。
- 载人车架的焊接应由具备能力的人员完成；焊缝进行外观检查，关键节点采用适当无损检查或由专业人员复核。

### 转向与制动
- 转向节、横拉杆、脚控机构设置实体限位；任何拉索松脱不得让车轮无约束摆动。
- 制动系统应独立于传动链；驻车锁止不得仅靠链条、飞轮或摩擦保持。
- 驾驶员必须能在双脚留在脚托内、双手按设计动作操作时停车；否则控制架构退回重设计。
- 制动器、拉索、支架和轮毂须按实际质量/速度/坡度工况选型；额定值和实测制动距离入档。

### 牵引与购物车
- 牵引销采用双剪切布置并有独立保险销；检查孔边距、耳板厚度、销轴材料和弯曲。
- 购物车满载时牵引点不得使前轮抬起；低速转弯不得与车架/乘员发生碰撞。
- 回归机构在规则澄清前只制作非储能的几何样件；弹簧储能件不得采购、安装或测试。

### 卸货台
- 装置完全独立于车辆；底座抗滑、抗倾覆。
- 翻转轴设置机械止挡和双重锁止；手柄松手后不得自行坠落。
- 导槽末端限位，物品不飞出结账区；夹点设置护罩。

## 4. 配重测试顺序

1. 空车静态检查与尺寸记录。
2. 25%设计载荷，检查挠度、异响、紧固件。
3. 50%、75%、100%设计载荷逐级重复；每级卸载后检查永久变形。
4. 仅在配重阶段无异常后，进行无人低速滚行、转向和制动测试。
5. 只有在专业检查、配重试验、制动测试均通过并由指导教师批准后，才考虑极低速载人验证。
6. 出现裂纹、焊缝异常、轴承松脱、转向卡滞、制动衰退、结构永久变形，立即停止。
