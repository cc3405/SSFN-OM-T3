# Group II · OMER Shopping Service — 全新竞赛工程包

> 设计基线：2026–2027 Problem 1《OMER 的购物服务》题面 1.md；组别 II；7 名队员。本文档集独立于仓库历史方案，旧项目规划、旧代码和旧机械方案均不构成本方案约束。

## 方案总览

**暂定主题：月面补给站 / LUNA-3。** 一名乘员驾驶原创人力车辆，车辆牵引可拆卸购物车完成三件物品采购；缺货时由购物助理向驾驶员提出替代并取得明确批准；在结账区用独立、纯人力操作的三位翻转卸货台把三件物品送入结账区域；结账后车辆牵引购物车越过起始线所在垂直平面，车辆停止并释放购物车，购物车以可视化机械回归机构返回购物车区域。

## 本版的关键设计选择

1. **载人车：单人手摇链传动 + 脚控转向。** 驾驶员坐在固定座椅中，双手操作中心手摇曲柄，经链条/飞轮驱动后轴；双脚始终放在脚控转向踏板上，通过拉索/连杆转动前轮转向横拉杆。乘员全程由座椅、脚踏和车架支撑，不以脚蹬地推进。
2. **购物车：拖挂充能、释放回归的机械模块。** 牵引行进期间，购物车车轮经单向离合和减速机构给封闭式扭簧储能；释放后先由凸轮切换方向，再由限速驱动轮将购物车导向原购物车区域。此机制具原创展示潜力，但“购物车自带储能驱动是否符合 B11”必须提交官方澄清；未获明确许可前不得冻结为正式比赛方案。
3. **卸货：独立三位翻转台。** 自立底座与车辆完全分离；三格承托盘由队员手动摇柄驱动蜗杆/扇形齿轮翻转，三件商品经宽口导槽进入结账区域。使用机械止挡和二次锁销，禁止依靠电机。
4. **表演：月面温室紧急补给。** 购物清单、缺货标识、替代批准、结账核验和回归动作都用可见道具及简短台词呈现。

## 重要边界

- 题面规定 8 分钟、165 美元、总分 250（解题 200 + 风格 50）。最终成本必须按 2026–27 活动手册定义核算；本目录价格只是采购预算假设。
- 图 A 标注“不按比例”。本文件中的尺寸是**初始工程尺寸**，须按实际赛场测量、标准门口通行和队员人体尺寸调整。
- 任何车辆尺寸、承重、制动距离、购物车回归范围、卸货可靠性均未实测；不得把设计目标写成已达成。
- 题面 B7c 的维修限制、B7d 乘坐定义、B11 购物车释放时序、活动手册一般规则与赛场主任提供的场地信息，均须在实物冻结前复核。
- 方案不依赖 ESP32、传感器或电动执行器完成题目得分项；纯机械架构减少故障点，音乐与舞台效果由现场表演完成。
