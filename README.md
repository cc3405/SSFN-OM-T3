## 核心方案摘要

- 乘员双踏摆交替驱动的原创四轮低重心车辆；乘员全程由车辆支撑，脚不触地。
- 可拆卸购物车随车移动并承载三件物品。
- 购物助理明确交付订单、批准缺货替代，并在结账时检查三件物品。
- 与车辆完全分离的原创手摇升降—回转卸货装置，将三件物品转移到结账区域。
- 连接的购物车穿过起始线所在垂直平面、车辆停止后释放；购物车最终静止时至少一个接地点位于购物车区域；购物车静止前车辆保持在起始线上或起始线之外。
- 8分钟硬上限、$165成本上限；当前预算估算$135，须按当年活动手册核验成本口径。

## 重要合规说明

购物车自身预储能弹性回归机构是一个**待官方澄清的高风险概念**，目前不能视为已获许可。设计文件已给出澄清草案、降级路径和测试门槛。若官方答复不支持，必须改用经确认合规的替代方案。

题目明确要求参考 2026–2027《头脑奥林匹克活动手册》，并持续查看官方澄清。请在设计冻结和比赛前核验一般规则、成本计价、安全、外部援助、队籍标志及当年表格要求。实际场地尺寸、地面条件和标线位置应向当地赛场主任确认。

## 工程状态

当前提交的是**概念基线、工程设计文档和算术门禁**，不是已制造或实测通过的成品。预算、时间和分数目标是计划值，不是实测结果或得分承诺。任何机械安全、规则合规或比赛成功状态，都必须由真实测试记录支持。

本方案刻意不采用自动驾驶、无线遥控或复杂电子控制：它们不会自动带来题目分数，反而会增加故障面。当前方案的主要工程工作集中在车辆安全、独立卸货机构和购物车回归可靠性。
