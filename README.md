# 航天未来科技组 · OMER 太空补给服务

> 以三组文件夹中的材料为题材和任务流程参考，独立选择可行技术路线的 14 天交付方案。

本仓库目标是在 14 天窗口内（10 天各 2 小时、4 天各 12 小时，约 68 小时）完成可运行、可演示、可验收的 OMER 购物服务原型。**三组文件夹仅作为项目材料来源，不要求沿用仓库其他任何文件的架构、代码或设计；允许直接重构。**

## 项目原则

- 三组文件夹提供任务优先级、剧情、预算参考和外观方向；实现方式可以全部重新设计。
- 14 天优先打通「订单交接 → 程序自主选择缺货替代品 → 购买/装载 → 自制机构卸货 → 车辆返回停车区」。
- 主控改用 **ESP32-S3 N16R8**；按团队提供的报价 ¥25 暂列预算，购买前确认具体板型、Flash/PSRAM 配置和引脚图。
- 采用低速差速两驱底盘、编码器电机、简单卸货翻斗和可重复停靠；复杂功能只有在门槛测试通过后才加入。
- ESP32-S3 GPIO 是 3.3V 且不耐 5V 输入；超声波 Echo 等信号必须先做电平适配。引脚文档为初稿，实物核验前不可直接上电。
- 购物车采用被动拖挂/释放的简化设计；车辆返航由车辆自身完成。正式比赛仍以完整题面及当季官方澄清为准。
- 预算上限为 **165 美元**，按赛事成本核算口径记录实际购买成本；人民币预算只是采购估算，不等于规则成本已核验。
- 海淀只作为团队计划的训练/收货区域约束：采购优先中国大陆现货、北京/华北仓和明确到货日期；不推断具体地址或场地已经落实。

## 测试状态

仓库包含决策逻辑、采购文档和引脚初稿，但硬件、固件、场地和机械系统尚未通过本次远程操作完成实机验证。没有测试记录的项目一律标记为“未测”，不宣称已经实机跑通。
