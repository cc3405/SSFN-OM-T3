# 航天未来科技组 · OMER 太空补给服务

> 以三组材料为主线、吸收 D5 可复用技术内容的 14 天可交付版本计划。

本仓库用于 2026—2027 年度头脑奥林匹克长期题 1「OMER 的购物服务」的方案整合、硬件固件、演出组织与验收记录。目标不是堆叠最高复杂度，而是在北京市海淀区的可用场地内，完成**可运行、可演示、可验收**的最小可靠版本。

## 冲突裁决规则

- **三组优先**：先打通「接单 → 采购/缺货替代 → 卸货 → 购物车回位 → 结束」完整任务链。
- D5 中可复用的结构、Arduino 代码和展示内容作为候选实现，不视为已经通过实机验证。
- 发生冲突时，以赛题原文及正式澄清为最高约束，其次按用户指定的「三组优先」，最后才是 D5 方案。
- 替代品由预设规则自主选出；购物助理在舞台上明确批准并向裁判展示结果。助理不参与算法选品，以兼顾三组的自主决策要求与 D5 的剧情/展示要求。
- 预算硬上限为 **165 美元**。任何采购都需记入实际成本表；未取得报价的数字只能标注为估算。
- 14 天内优先交付可靠基础流程；自动导航、陀螺仪融合、OLED 等高级能力必须通过门槛测试后才可纳入比赛流程。

## 仓库现状与验证口径

本次整合分支新增项目级计划、验收清单和风险登记。硬件、场地与无线链路未在本次远程仓库操作中实际运行，因此**不能声称小车已实机完成任务或达到比赛成功率**。每项测试需记录日期、场地、配置、重复次数、结果与视频/照片证据。

## 14 天交付原则

- 第 1–2 天：确认规则、尺寸、团队责任人、预算与可用场地。
- 第 3–5 天：先完成底盘移动、手动急停/失联停车与基础遥控。
- 第 6–8 天：完成清单与替代决策、拾取/装载和卸货的单项测试。
- 第 9–11 天：集成购物车拖行、释放与回位；先用人工标记点/低速模式确保可重复。
- 第 12–13 天：全流程计时、故障注入、成本和规则审查。
- 第 14 天：冻结版本、演示验收、提交证据和未通过项清单。
