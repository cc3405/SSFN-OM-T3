## 设计状态

- 预算估算：**$145 / $165 上限**，尚需按活动手册成本口径及真实票据核算。
- 表演目标：**7:15 / 8:00 上限**，需完整彩排验证。
- 车辆：单人手摇链传动、脚控前轮转向；尺寸和承重仍需工程验证。
- 卸货：独立自立式三位翻转台，由队员人力操作。
- 购物车回归：牵引过程机械储能、释放后回归的概念必须先取得官方澄清许可；未获许可不得启用。
- 目前没有声称载人安全、实物性能或比赛结果已通过测试。
