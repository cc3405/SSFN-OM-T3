## 建议的架构边界

1. **任务层**：显式状态机：`WAIT_ORDER → CHECK_STOCK → CHOOSE_SUBSTITUTE → LOAD → CHECKOUT → UNLOAD（若适用）→ RELEASE（若适用）→ RETURN → PARKED → DONE`。每个状态都有进入条件、成功条件、超时/故障分支和可复位方式。
2. **决策层**：替代规则纯函数化；输入包括商品类别、缺货标志、候选项、预算和价格；输出唯一商品或 `NEEDS_ASSISTANCE`，同时记录选择理由。
3. **运动层**：低速差速驱动；使用 AB 相编码器进行方向与距离反馈；超声波只作为近距辅助，不把单一超声波当作定位或安全系统。
4. **执行器层**：车辆上的舵机/舱门若保留，只能服务于非题目规定的其他功能；不能把车载舵机、翻斗或舱门当作题面要求的卸载装置。题目规定的卸载装置必须与车辆分离、原创、自制，并可由队员直接人力操作；限位或日志只能作为辅助证据，不能代替三件物品实际进入结账区的结果。
5. **安全层**：硬件急停物理断开电机驱动电源；复位默认禁用；输入信号适配到 3.3V；异常/传感器失效时进入安全停止状态。

## 竞争力不是“功能数量”

建议把竞争力建立在可重复性、可解释性和故障恢复上，而不是加入未经验证的视觉识别或无线控制：

- **可靠性**：完整流程连续 5 次通过；每次记录失败分类和修复。
- **可解释的自主选择**：展示缺货输入、候选列表、约束过滤、最终选择及原因，操作员不能临时替程序选结果。
- **工程可复现**：固定 BOM、固件版本、接线图、测试视频和日志。
- **故障安全**：传感器无回波、串口命令异常、复位和急停都不会造成持续驱动。
- **呈现质量**：可视化订单/替代决策和卸货反馈，但不能让装饰影响任务可见性或阻碍运动。

## 分阶段验收门槛

- **G0 规则**：确认组别、拿到完整题面、逐项列出规则及澄清，完成场地尺寸图。
- **G1 电气**：不接电机先验证 MCU/传感器逻辑；测量电平；验证保险丝和硬件急停。
- **G2 构建与单元**：固件可构建；替代决策测试覆盖有货、缺货、同价、超预算、无候选。
- **G3 底盘**：离地验证电机方向；再低速直行/转弯；AB 编码器计数方向正确；固定路线重复 10 次。
- **G4 机构**：假商品逐件、三件连续卸货；限位状态可信；失败能安全停止和复位。
- **G5 集成**：完整场地连续 5 次无关键安全或规则失败。未通过就删减/降级，不将未实现功能写成已完成。
