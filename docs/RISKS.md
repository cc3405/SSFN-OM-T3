## 需要教练/官方确认

1. 购物车“自行行进”的精确规则解释，以及主动驱动/释放后电机是否允许。
2. 赛题中对购物车、车辆、卸货装置的电源/连接方式限制及相关官方澄清。
3. 165 美元成本表的具体计入规则、重复用途物品和捐赠材料的申报口径。
4. 海淀训练场地的可用时间、尺寸与安全要求。

## 当前已知代码/依赖风险

- `doc_driver.py` 使用固定的 `/root/.codebuddy/...` 路径和共享的 `/tmp/edsdk_args.json`，离开对应工作台环境不能直接运行。
- 车辆程序引用 RF24、Servo、Wire、SPI、Adafruit GFX/SSD1306；实际编译前需要安装并锁定库版本。
- 不同 `.ino` 目标包含独立的 `setup()` 与 `loop()`，应分别作为不同 Arduino sketch 编译，而非拼成一个程序。
- D5 方案中的硬件参数（轮距、编码器计数、回位距离等）均需实测标定，不能直接当作已验证常数。
