# 完整采购 BOM（一次性采购准备版）

> 版本：PURCHASE-BOM-1.0  
> 目标：ESP32-S3、12V 双电机差速底盘、商品抓取机械臂、购物车挂接/释放机构，以及**与车辆完全分离的独立人力卸载装置**。  
> **重要状态：这是完整的采购准备清单，不是已经完成尺寸冻结的可盲目下单清单。** 现有仓库没有整机 CAD、购物车实测尺寸、道具质量/尺寸、电机堵转电流和舵机负载计算。带“下单前确认”的条目必须先实测或取得卖家数据，不能仅凭商品标题下单。  
> 价格不填虚构报价；采购时将实际含税/运费价格录入成本表，并按赛事正式成本口径核算。

## 10. 采购验收与装配顺序

- [ ] 每件商品核对型号、数量、实物尺寸、额定电压、电流、接头和卖家数据表。
- [ ] 电机必须取得该 SKU 的额定/堵转电流；没有数据就先不买电池/BMS/保险丝最终规格。
- [ ] 舵机必须取得工作电压、堵转电流和力矩曲线；没有数据就先不定 6V 电源最终规格。
- [ ] 电池必须是成品合规电池组，核对 3S、12.6V 充电器、BMS 持续电流、接头极性和运输要求；不购买散装裸电芯自行拼包。
- [ ] 保险丝、接触器、开关、线径按电流计算；急停要能物理切断电机驱动能量。
- [ ] ESP32-S3 GPIO 只能接允许范围内的逻辑电平；HC-SR04 Echo 和编码器输出不得未经核验直连。
- [ ] 先完成无电装配、通断检查和电源极性检查；再单独测试逻辑电源、传感器、单侧电机、舵机。
- [ ] 车轮悬空、低占空比、限流条件下首次测试；验证急停、复位默认禁用和失联停止。
- [ ] 购物车挂接/释放与独立卸载装置分别验收；连续三件物品卸载必须由队员直接人力完成。
- [ ] 完成整机实测和连续 5 次全流程验收后，才能将 BOM 标记为“最终冻结”。
