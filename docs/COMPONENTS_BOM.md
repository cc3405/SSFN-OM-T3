# 采购清单与型号建议（大陆电商检索版）

> 版本：MVP-1；目标：14 天内先做出低速、可复位、可测试的地面购物服务车。型号为可搜索的规格组合，不代表已经下单、核实库存或完成实测。下单前请核对电压、轴径、安装尺寸和卖家实物图。

## 设计决策

- 项目内容以 `3组/` 中的计划、剧本、预算表和设计图为创意/流程参考；不要求沿用 D5 的机械或代码设计。
- 采用**差速两驱 + 后万向轮 + 简化翻斗/舱门**，先不做复杂回转臂、购物车独立驱动、RF24 多控制板和 OLED。
- 最终任务按官方 Problem 1 简介表述为：完成购物任务后，车辆被释放并返回停车位置。不要把 D5 中“购物车主动回位”当作必须沿用的设计。正式比赛仍以完整题面和当季澄清为准。
- 本清单假设是**地面小车搬运道具**，不是载人车辆。如果正式题面/你们的组别要求车辆载人，先暂停本清单采购，底盘、制动和驱动必须重新做安全设计；不能用下列小型电机载人。

## 关键电气约束

1. 电池电压、电机电压、驱动板额定电流必须匹配。先测空载电流，再短时测启动电流；若电机堵转电流超出驱动板/接线能力，必须换驱动或电机。
2. BTS7960 模块常见宣传的高峰值电流不是持续电流保证。装保险丝、绝缘、应力释放和散热；电池与驱动器之间不得裸露短路点。
3. 舵机使用独立降压供电，控制器与舵机电源共地；先空载测舵机动作，再连接翻斗。
4. 任何夹点、剪切点和旋转轴先加护罩。初期只用轻质假商品、低速、空场测试。
5. 车辆回停车位功能优先采用可重复的低速返航/固定标记停靠。编码器闭环可作为后续升级；14 天内如果自动定位不稳定，采用可解释、可验收的简化实现，但不得违反正式题面。

## 发货筛选（只用于物流，不作为项目地点推断）

- 发货地：优先中国大陆现货；如能选择，优先北京仓或华北仓。
- 发货时效：优先“24 小时内发货”，下单前向卖家确认实际出库日期。
- 到货时效：以结算页预计送达日期为准，需能在采购日后 2–3 天内到达北京海淀团队指定收货地址；具体地址由团队在电商平台自行填写。
- 本文不推断训练场地址，也不代为下单、支付或确认物流。
- 电池类商品须确认平台允许该型号配送至收货地址，且包装/运输合规。
