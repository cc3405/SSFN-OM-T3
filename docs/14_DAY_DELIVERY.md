# 14 天落地计划（北京海淀）

计划以团队确认开工日为 D1。海淀仅用于收货和现场实施的区域约束；团队需自行确认训练场地、尺寸和可用时间。本计划不表示场地已预约或货物已下单。

| 天 | 任务 | 证据 | 退出条件 |
|---|---|---|---|
| D1 | 精读官方题面/澄清；确认车辆返航、卸货和购物车释放规则 | 规则矩阵、问题清单、责任人 | 每条硬约束有验证方法 |
| D2 | 采购定型，按具体型号比价；确认北京/华北仓、出库时间和到货承诺 | 采购清单、结算截图、物流预计送达日 | 关键物料可在 2–3 天内到货；预算预测符合赛事上限 |
| D3 | 底盘装配、轮子离地测试、电源和急停布线 | 接线图、空载视频 | 方向正确，无短路/裸露电源 |
| D4 | 低速直行、转弯、编码器读数、失联停车 | 10 次重复测试表 | 无失控；否则停留修复 |
| D5 | 编码器返航/固定路线状态机 | 起点/终点误差记录 | 固定路线可重复停靠；无法达成则降级到更简单路线 |
| D6 | 缺货替代规则、输入接口、日志输出 | 单元测试和现场演示 | 有货、缺货、有候选、无候选结果均确定 |
| D7 | 拾取和装载机构 | 单项视频与失败记录 | 三件道具分别能稳定装载 |
| D8 | 制作轻载翻斗/舱门卸货机构 | 结构图、夹点检查、单项视频 | 不靠队员直接取货完成卸货 |
| D9 | 三件连续卸货与卡货处理 | 10 轮测试表 | 至少 9/10 轮完整卸货成功；否则简化机构 |
| D10 | 被动购物车挂接/释放，按官方规则检查 | 结构照片、慢速视频、澄清依据 | 不把购物车滑行当成车辆返航 |
| D11 | 集成采购、卸货和车辆返航状态机 | 全尺寸路线图、计时表 | 每个状态可停止、复位、继续 |
| D12 | 全流程重复测试和故障注入 | 原始数据、视频、问题单 | 5 次流程无关键安全/规则失败 |
| D13 | 代码/结构冻结、预算审计、舞台彩排 | 版本号、成本表、录像 | 所有变更均做回归测试 |
| D14 | 验收演示、归档未通过项和证据 | 验收表、证据目录 | 如实标注通过/失败/未测 |

## 采购物流约束

- 只把“北京/华北仓、现货、24 小时内发货、预计送达日期”作为物流筛选条件，不用地理信息推断团队具体地址。
- 到货目标为采购后 2–3 天内送达团队自行填写的北京海淀收货地址；以电商结算页和卖家确认信息为准。
- 锂电池需确认可合法配送、匹配充电器和保护板。电机、驱动器、电池没到齐前不要改成不同电压规格。

## 降级策略

- 编码器导航不稳定：先简化路线、降低速度、加入固定停靠标记，不临时堆叠复杂传感器。
- 翻斗卡货：改大开口、低摩擦导向面和更简单的锁扣；不要在 D8 后增加复杂机械臂。
- 物流延误：优先本地现货/可当日自提的等规格物料，替换前重新核对电压、轴径、额定电流和尺寸。
- 未通过完整流程门槛：明确展示已通过的单项功能，不宣称整车已验收。
