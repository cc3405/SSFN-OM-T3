# ESP32-S3 N16R8 引脚分配与接线安全

> 状态：软件接口已补充，仍是待实物核验的候选映射。禁止把 5V 信号直接输入 ESP32-S3 GPIO。

## 1. 目标配置

- 主控：ESP32-S3 N16R8，3.3V GPIO。
- 左右轮各一个 BTS7960/IBT-2 驱动器、两个带 AB 编码器的减速电机。
- 两个 HC-SR04 作为近距离防撞辅助。
- 商品抓取臂候选方案：3 个 4.8–6V 舵机（肩、肘、夹爪），经 PCA9685 I²C 驱动板控制。
- 两个微动限位开关。
- 急停开关物理切断电机驱动电源，不依赖 MCU。

## 2. GPIO 与外设映射

| 功能 | ESP32-S3 GPIO | 方向 | 说明 |
|---|---:|---|---|
| 左电机 RPWM / LPWM | 4 / 5 | 输出 PWM | 驱动逻辑需实测 |
| 右电机 RPWM / LPWM | 6 / 7 | 输出 PWM | 驱动逻辑需实测 |
| 两块驱动器 R_EN/L_EN | 21 | 输出 | 共享使能；加外部下拉并核验 3.3V 兼容性 |
| 左编码器 A / B | 15 / 8 | 输入 | A 相 CHANGE 中断、读取 B 相估计方向 |
| 右编码器 A / B | 16 / 9 | 输入 | 同上 |
| 左 HC-SR04 TRIG / ECHO | 10 / 11 | 输出 / 输入 | Echo 必须降至 3.3V 以下 |
| 右 HC-SR04 TRIG / ECHO | 12 / 13 | 输出 / 输入 | Echo 必须降至 3.3V 以下 |
| PCA9685 SDA / SCL | 1 / 2 | I²C | 地址 0x40；需核验实际板型 |
| PCA9685 CH0 / CH1 / CH2 | — | PWM 输出 | 肩 / 肘 / 夹爪 |
| 限位开关（预留） | 17 / 18 | 输入 | 当前仅读取电平，尚未接入运动互锁 |

编码器当前使用 A 相 CHANGE 并采样 B 相，属于每个 A 相周期的双边沿方向计数，不等同于完整 x4 解码。必须根据编码器数据手册和实测标定每转计数，不能直接把原始计数当作距离。

## 3. PCA9685 抓取臂接口

- I²C 地址：0x40（模块地址焊盘改变时需同步修改固件）。
- PWM 频率：50Hz；固件直接通过 `Wire` 配置 PCA9685，无需第三方库。
- 通道：CH0 肩关节、CH1 肘关节、CH2 夹爪。
- 当前固件脉宽候选值 600–2400µs，命令角度限制 20–160°；这只是初始软件限制，不是舵机或连杆的安全工作范围。
- `armenable` / `armhome` 将三个通道设为 90°；`servo shoulder 110` 等命令设置单轴；`armoff` 关闭 PWM 输出信号，不切断舵机电源。
- 舵机必须由独立稳压电源供电，按实际电源/驱动要求共地。测量堵转电流并确保电源、线材、连接器和保险保护匹配。
- 初次标定时拆除连杆或断开舵机电源，逐个确认脉宽方向和机械端点，再安装连杆低速测试。不得让舵机撞机械限位或长时间堵转。

**抓取臂不得替代比赛要求的独立卸载装置。** 独立卸载装置与车辆完全分离，且由队员直接人力操作；不连接 PCA9685，也不由车辆固件控制。

## 4. 电源、电平和急停

1. ESP32-S3 的 3V3 仅供逻辑和小负载，不给电机或舵机供电。
2. 电池正极经主保险丝后分支供电：电机驱动、舵机稳压电源、开发板输入分别核算。不要把未经确认的电池电压接到 5V 或 3V3。
3. ESP32、传感器信号地、驱动器逻辑地和舵机电源地按电路要求共地；大电流回路与信号线分开布线。
4. 常见 HC-SR04 Echo 是 5V 输出。可用经计算的分压或合适电平转换器；实测 MCU 端电压不得超过芯片规定值。
5. 编码器输出电平也必须核验；5V 输出不可直连。
6. 两块驱动器的 R_EN/L_EN 不得悬空。GPIO21 共享控制仅在模块允许且 3.3V 逻辑兼容时使用，并加外部下拉。急停必须物理切断驱动电源。

## 5. N16R8 特别避让

- GPIO35、GPIO36、GPIO37 在常见 Octal PSRAM N16R8 模组上被内部存储器占用，不分配给外设。
- 避开 GPIO0、GPIO3、GPIO45、GPIO46 等启动绑带相关脚，除非按具体板型设计并验证。
- GPIO19/20 常用于原生 USB D-/D+；GPIO43/44 常用于 USB-UART 日志，调试阶段尽量保留。
- Flash/PSRAM 设定必须与实际模组一致。

## 6. 上电验收顺序

- [ ] 仅给 ESP32 供电，确认下载、串口和复位正常；电机使能保持 LOW。
- [ ] 测量传感器/编码器输入电压，确认 MCU 端不超过允许范围。
- [ ] 检查 PCA9685 地址、50Hz PWM 和三通道输出；先无负载标定舵机行程。
- [ ] 车轮悬空、限流/低占空比测试单侧电机；确认方向和 PWM 互锁。
- [ ] 验证急停在 MCU 卡死/重启时仍能物理断开驱动电源。
- [ ] 低速测试编码器方向和计数，随后标定轮径、轮距和每转计数。
- [ ] 所有结果按 `docs/ACCEPTANCE.md` 记录，未实测不得标记通过。
