# ESP32-S3 N16R8 引脚分配与接线安全（初版）

> 状态：设计草案，尚未进行硬件测试。接线前核对实际板型和引脚图。**禁止把 5V 信号直接输入 ESP32-S3 GPIO。**

## 1. 目标配置

- 主控：ESP32-S3 N16R8，3.3V GPIO。
- 左右轮各一个 BTS7960/IBT-2 驱动器。
- 两个带 AB 编码器的减速电机。
- 两个 HC-SR04，作为近距离防撞/停靠辅助。
- 候选商品抓取臂：3 个 4.8–6 V 舵机（肩、肘、夹爪），经 PCA9685 I²C 驱动板控制；尚未采购或集成。
- 两个微动限位开关。
- 急停开关物理切断电机驱动电源，不占 MCU GPIO。

## 2. 建议 GPIO 表\n\n抓取臂候选接口：PCA9685 SDA/SCL 暂定 GPIO1/GPIO2，CH0–CH2 分别控制肩、肘、夹爪。此分配尚未实物核验；确认实际板型和 I²C 引脚后再接线。

| 功能 | ESP32-S3 GPIO | 方向 | 说明 |
|---|---:|---|---|
| 左电机 RPWM | GPIO4 | 输出 PWM | 仅为初始分配，先确认驱动模块控制逻辑 |
| 左电机 LPWM | GPIO5 | 输出 PWM | 正反转切换应先将两路输出置于安全状态 |
| 右电机 RPWM | GPIO6 | 输出 PWM | 同上 |
| 右电机 LPWM | GPIO7 | 输出 PWM | 同上 |
| 两块驱动器的 R_EN/L_EN（共享使能） | GPIO21 | 输出 | 两模块共用一个使能信号；只有确认 3.3V 逻辑兼容后才直连，否则加电平转换；加外部下拉确保复位时禁用 |
| 左编码器 A | GPIO15 | 输入/中断 | 先确认编码器输出电压；如为 5V，需电平转换 |
| 右编码器 A | GPIO16 | 输入/中断 | 只读 A 相用于初版速度/里程估计 |
| 左 HC-SR04 TRIG | GPIO10 | 输出 | 3.3V 高电平通常可作为触发；实际模块需验证 |
| 左 HC-SR04 ECHO | GPIO11 | 输入 | **先经过电阻分压/电平转换，不能直连 5V Echo** |
| 右 HC-SR04 TRIG | GPIO12 | 输出 | 同上 |
| 右 HC-SR04 ECHO | GPIO13 | 输入 | **先经过电阻分压/电平转换，不能直连 5V Echo** |
| 预留 GPIO | GPIO14 | 预留 | 不再分配给车载卸货舵机；抓取臂候选方案使用 PCA9685 |
| 预留限位输入 | GPIO17 | 输入 | 仅在实际机构需要且电路确认后使用 |
| 预留限位输入 | GPIO18 | 输入 | 仅在实际机构需要且电路确认后使用 |

GPIO 数量：底盘和传感器约 11 个；抓取臂候选方案通过 PCA9685 I²C 控制，不直接占用 MCU PWM 引脚。若 AB 两相编码器均读取，将编码器 B 相分配至 GPIO8、GPIO9（共增加 2 个）。GPIO21 是两块驱动器的共享使能输出，模块使能输入须先确认 3.3V 兼容性；若不兼容则通过逻辑电平转换。驱动使能应加外部下拉，确保 MCU 复位/引脚高阻时驱动保持禁用。若需要两块驱动器分别使能，再按具体板型另行分配 GPIO，避开启动绑带脚。

## 3. 电源和电平

1. ESP32-S3 的 3V3 仅供逻辑和小负载，不给电机或抓取臂舵机供电。
2. 电池正极经主保险丝后分支供电：一支到电机驱动电源；另一支经合适的降压模块供舵机；开发板按其 USB/5V 输入要求供电。不要把未经确认的电池电压接到 5V 或 3V3 引脚。
3. ESP32、编码器/传感器信号地、驱动器逻辑地和舵机降压模块地按电路要求共地；大电流回路与信号线分开布线，避免电机噪声让 MCU 复位。
4. HC-SR04 常见 Echo 是 5V 输出。示例分压可采用 ECHO 到 GPIO 之间串联 1 kΩ、GPIO 到 GND 之间 2 kΩ（输出约 3.3V）；实际应以模块输出和电阻误差核算。也可用合适的双向/单向电平转换器。
5. BTS7960/IBT-2 的不同版本可能对 3.3V 控制高电平的识别能力不同。查模块原理图/数据，必要时加逻辑电平转换；先在车轮悬空条件下验证，绝不先装载重物测试。
6. 两块驱动器的 R_EN/L_EN 不能悬空：按具体模块电路把使能输入正确连接到 GPIO21 共享控制（若模块允许），并加外部下拉；若 3.3V 不能可靠识别则加电平转换。上电默认应禁用电机；急停必须能在软件失控时切断驱动电源。

## 4. ESP32-S3 N16R8 特别避让

- GPIO35、GPIO36、GPIO37 在常见 Octal PSRAM N16R8 模组上被内部存储器占用，不分配给外设。
- 避开 GPIO0、GPIO3、GPIO45、GPIO46 等启动绑带相关脚，除非按具体板型设计并验证上电状态。
- GPIO19/20 常用于原生 USB D-/D+；如使用原生 USB，不分配给外设。
- GPIO43/44 常用于 USB-UART 桥串口日志；调试阶段尽量保留。
- 部分开发板的 RGB LED 可能占用 GPIO38 或 GPIO48；本表不依赖这两个脚。
- N16R8 的 Flash/PSRAM 设定要与实际模组一致。Arduino IDE 可先选择 ESP32S3 Dev Module，按板子资料设置 Flash 16MB 与 OPI PSRAM；上传串口与 USB 方式因板型不同而异。

## 5. 上电验收顺序

- [ ] 只给 ESP32 供电，确认下载、串口日志和复位正常。
- [ ] 测量每个传感器输出电压，确认进入 GPIO 的信号不超过 3.3V。
- [ ] 若制作抓取臂，测试 PCA9685 与独立舵机电源；逐个标定舵机行程，确认动作不会使 ESP32 复位或夹伤人员。
- [ ] 车轮悬空、限流/低占空比条件下测试单侧电机；验证 RPWM/LPWM 不会同时输出导致异常。
- [ ] 验证急停在 MCU 卡死/重启时仍能物理断开电机驱动电源。
- [ ] 先低速、空场测试编码器方向、距离传感器和限位逻辑，再做整车任务测试。

以上只是建议映射；未经实物核对与台架测试前，不应据此直接给整车上电。
