# ESP32-S3 N16R8 固件

## 环境与依赖

- Arduino IDE 2.x
- Espressif Arduino-ESP32 platform 3.x
- 固件使用 Arduino core 自带的 `Wire`，不依赖第三方 PCA9685 库。
- Board/Flash/PSRAM/USB 上传选项必须按实际 N16R8 开发板设置。

官方安装文档：<https://docs.espressif.com/projects/arduino-esp32/en/latest/getting_started.html>。

## 当前实现

| 子系统 | 已实现的软件功能 | 尚未证明/实现 |
|---|---|---|
| 底盘 | 四路 PWM、短时手动脉冲、驱动默认禁用、超时停止、超声波近距保护 | 自主导航、路径规划、速度闭环、自动返航 |
| 编码器 | 左右 AB 两相；A 相 CHANGE 中断并采样 B 相方向 | 每转脉冲数标定、轮径/轮距标定、里程闭环 |
| 抓取臂 | PCA9685 I²C 地址 0x40；CH0/1/2 控制肩/肘/夹爪；串口角度命令 | 机构制作、舵机供电、端点标定、抓取策略与实物测试 |
| 安全 | 上电电机禁用；PCA9685 舵机信号上电全关；无回波按障碍处理 | 硬件急停、实际电平/电流/温升验证 |

**抓取臂是商品取放机构，不是卸载装置。** 题目要求的卸载装置必须与车辆分离、由队伍原创制作并可由队员直接人力操作；本固件没有、也不应增加车载卸货命令。

## 串口命令（115200 baud，换行结尾）

- 底盘：`help`、`status`、`arm`、`disarm`、`fwd`、`rev`、`left`、`right`、`stop`、`encreset`
- 抓取臂：`armenable`、`armhome`、`armoff`、`servo shoulder 90`、`servo elbow 90`、`servo grip 90`

执行 `armenable` 或 `armhome` 会令三个舵机信号到 90°；`servo <axis> <degrees>` 允许 20–160°。该角度范围是软件保护范围，不代表机构安全行程。必须先断开舵机电源或卸下连杆，逐个校准实际机械端点，再低速带载测试。执行 `armoff` 关闭 PCA9685 对应通道的 PWM 信号；它**不会切断舵机电源**。

PCA9685 未检测到时，抓取臂命令不可用。驱动底盘的 `arm` 与抓取臂的 `armenable` 是不同命令。

## 引脚与接线

| 功能 | GPIO / 接口 |
|---|---:|
| 左电机 RPWM / LPWM | 4 / 5 |
| 右电机 RPWM / LPWM | 6 / 7 |
| 两块驱动器共享使能 | 21 |
| 左编码器 A / B | 15 / 8 |
| 右编码器 A / B | 16 / 9 |
| 左超声波 TRIG / ECHO | 10 / 11 |
| 右超声波 TRIG / ECHO | 12 / 13 |
| PCA9685 SDA / SCL | 1 / 2 |
| PCA9685 CH0 / CH1 / CH2 | 肩 / 肘 / 夹爪 |

以上是候选映射，接线前核对具体开发板引脚图。所有进入 ESP32-S3 的信号必须满足芯片输入电压要求；常见 HC-SR04 Echo 需先降至不超过 3.3V。编码器若输出 5V，同样需要电平转换。

## 上电前安全要求

1. 硬件急停必须独立切断电机驱动能量；软件 stop 不能替代急停。
2. 电机驱动使能加外部下拉；先验证模块是否可靠识别 3.3V 高电平。
3. 舵机使用独立、足够电流的稳压电源，不能由 ESP32 3V3 引脚供电；与控制器按电路要求共地。
4. 初次舵机测试先断开舵机电源/卸下连杆，核验 PWM、供电极性和端点；避免夹伤、卡死和机械撞限位。
5. 首次底盘测试抬起车轮，先单侧、再低占空比整车测试。
6. 超声波无回波会阻止运动；传感器读数不能替代物理防护和急停。
